# 九霄问道 V1.7.5.2 CACHE53｜GitHub轻量部署包

基线：V1.7.5 CACHE51。

本包是纯前端热修，不执行SQL。

## CACHE53修复

- 灵骰问道中奖后，下注格边框与鱼虾灵局使用同一 `.fish-target-card.win` 发光效果。
- 大、小、豹子、数字1～6的命中状态直接按本局公共三骰结果计算，不再只依赖结算记录中的 `result_count`。
- 只有本人本局确实下注时，三颗公共骰全部停定后立即在本机显示“命中”高亮，不等待服务端结算状态。
- 不修改赔率、开奖、资金结算、联合庄、奖池和数据库。
- 保留120ms批量下注、本地倒计时、阶段边界同步等多人性能设计。

## 部署

1. 解压本ZIP并覆盖GitHub仓库根目录，包含 `.github`。
2. 推送 `main`，等待GitHub Actions build/deploy成功。
3. 不执行任何新增SQL。数据库继续沿用V1.7.5 CACHE51（104/105/106）结构。
4. 手机彻底关闭旧页面后重新打开；CACHE53会替换CACHE52/CACHE51前端缓存。
