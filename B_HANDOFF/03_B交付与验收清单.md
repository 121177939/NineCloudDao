# B线交付与验收清单

B线提交候选包前逐项确认：

- [ ] 未修改正式版本号、CACHE、开发锁和历史SQL；
- [ ] 没有提交Service Role Key、私钥、密码或生产密钥；
- [ ] 没有新增第二套灵石账户；
- [ ] 所有资金与关键动作均由服务端事务验证；
- [ ] 所有写操作具有`request_id`或等效幂等机制；
- [ ] 私牌、未公开信息和管理员数据未进入公共Broadcast；
- [ ] Realtime只承载通知，不作为资金或胜负权威事实；
- [ ] 没有恢复牌九每玩家1秒轮询或大厅5秒维护轮询；
- [ ] 没有让隐藏iframe继续请求、计时或播放动画；
- [ ] 新SQL可重复安全检查，包含前置条件和回滚说明；
- [ ] 提供正常、并发、余额不足、超时、断线重连测试；
- [ ] 提供修改文件清单、源哈希和冲突说明；
- [ ] 明确说明哪些测试未在生产Supabase或真实多账号环境执行。
