九霄问道 V0.15.5 FIX1 CACHE27 SQL执行说明

本包可从 V0.15.4 FIX5 CACHE25 直接升级。
若 V0.15.5 CACHE26 尚未部署，不需要补跑旧版 20/21/22 SQL。

请在 Supabase SQL Editor 中依次执行：

1. 23_V0.15.5_FIX1_升级前检查.sql
2. 24_V0.15.5_FIX1_CACHE27_洞府视觉修正发布门禁.sql
3. 25_V0.15.5_FIX1_升级后检查.sql

本次 SQL 只把客户端发布控制提升到 CACHE27，用于强制 PWA 载入新版前端。
不会新增或修改战斗属性表、角色字段、RPC、触发器、RLS、洞府结算规则或渡劫规则。
