# V0.15.1 源码变更报告（CACHE18修正版）

## 修正内容

1. 将鱼虾灵局40秒阶段分配修正为：30秒下注、2秒封盘、5秒开骰、3秒结算展示。
2. 客户端倒计时回退值改为30/32/37/40秒。
3. 三枚骰子在总时间第33、35、37秒依次停定，对应5秒开骰阶段。
4. 数据库新轮次与当前未结算轮次同步使用30/32/37/40秒时点。
5. 服务端规则元数据修正为round=40、betting=30、lock=2、reveal=5、settlement=3、next=0。
6. 九霄界闻庄家姓名和净赢净输播报保持V0.15.1原规则。
7. 客户端缓存提升为CACHE18。

## 未修改

- 赔率、法印概率、玩家庄5%佣金、荷老兜底、造化池、连续落注、页面布局和其他玩法规则均未修改。
