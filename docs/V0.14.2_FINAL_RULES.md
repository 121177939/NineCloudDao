# V0.14.2最终规则

## 九霄界闻

1. 任何新写入的公开消息都排在旧消息之前。
2. 排序唯一主键为`feed_sequence desc`。
3. `is_pinned`、`event_level`、`event_type`均不参与排序。
4. 旧数据按`created_at asc, id asc`补齐序号，新数据由数据库序列自动分配。
5. RPC默认返回30条，最多仍受`max_feed_rows`限制。
6. 前端每10秒刷新，并对RPC结果再次做严格新消息排序。

## 未修改内容

- 突破播报的触发条件。
- 机缘、赌坊、造化池和账号删除播报的生成条件。
- 赌坊FIX7A结算与概率。
- 贵宾雅间及造化池开奖。
- 角色境界、修为、灵石、功法、命格。
