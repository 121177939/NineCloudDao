# V0.14.8数据库变更

新增两张RLS表：`casino_fish_rounds_v0148`和`casino_fish_bets_v0148`。客户端无表直写权限，仅允许认证用户调用状态与下注RPC。

新增公共函数用于创建60秒轮次、结算到期轮次、生成个人历史摘要；新增认证RPC：`get_fish_shrimp_state_v0148(integer)`、`place_fish_shrimp_bet_v0148(text,text,text,bigint)`。

数据库迁移会把发布控制更新到V0.14.8 CACHE12。主迁移为单事务；下注扣款与下注记录同事务，失败会整体回滚。

注意：当前为服务端惰性推进，后续请求负责结算到期轮次；未增加pg_cron或其他常驻定时任务。
