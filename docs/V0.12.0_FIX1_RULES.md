# V0.12.0 FIX1 万运博弈楼正式规则

## 区域

市坊新增“万运博弈楼”：

- 大堂：灵骰问道、气运龟卜，玩家对荷老。
- 贵宾雅间：灵拳对弈、五行灵拳，玩家对玩家。
- 灵石造化池与修为造化池相互独立，不兑换、不混池。

## 统一公证费用

- 分出胜负的对局，抽取总赌注5%。
- 5%全部进入对应造化彩池，不再拆分永久回收部分。
- 整数资源按数据库整数运算向下取整。
- 玩家对局同招流局：双方赌注原数返还，不抽取费用。

## 大堂概率与赔率

### 灵骰问道

三枚六面骰共216种等概率结果：

- 小：4—10点且不是围骰，105/216，约48.61%，净赔率1:1。
- 大：11—17点且不是围骰，105/216，约48.61%，净赔率1:1。
- 围骰：三枚点数相同，6/216，约2.78%，净赔率1:34。
- 出现围骰时，大、小均负。

### 气运龟卜

- 吉：25%，净赔率1:3。
- 平：50%，净赔率1:1。
- 凶：25%，净赔率1:3。
- 角色气运只影响氛围文案，不改变真实概率。

## 玩家异步赌契

1. 玩家A创建赌桌并暗选招式，赌注立即冻结。
2. 玩家B选择招式后应局，赌注立即冻结。
3. 从玩家B应局时开始五分钟倒计时。
4. 双方在开奖前只能看见自己的招式，对手招式保持封存。
5. 五分钟后云端统一揭晓，一局定胜负。
6. 掉线不影响云端开奖。
7. 同招流局并全额返还。
8. 公开赌桌30分钟无人应局自动取消，也可由创建者主动散契。

### 灵拳对弈

- 磐石势克疾风刃。
- 疾风刃克流云盾。
- 流云盾克磐石势。
- 双方随机选择时：A胜33.33%、B胜33.33%、平局33.33%。

### 五行灵拳

- 金锐拳胜青木拳、厚土拳。
- 青木拳胜厚土拳、浪涛拳。
- 厚土拳胜浪涛拳、焚天拳。
- 浪涛拳胜焚天拳、金锐拳。
- 焚天拳胜金锐拳、青木拳。
- 双方随机选择时：A胜40%、B胜40%、平局20%。

## 修为局

- 元婴期及以上开放。
- 单次最低50,000修为。
- 单次最高为“当前修为减当前大境界初期门槛”的20%。
- 输修为后，根据剩余修为重新匹配当前大境界内的小境界，并同步基础吐纳。
- 绝不跌出当前大境界。例如元婴后期可跌至元婴中期或元婴初期，但不能跌至金丹期。
- 赌场跌小境界不产生伤势、不增加突破失败补偿、不触发大跌境锁。
- 赢得修为只增加累计修为，不自动突破。

## 造化彩池

- 每完成一场有效胜负局，参与者获得对应资源的一张造化签。
- 每名角色每种资源每日最多10张。
- 两个彩池各自每两小时开启一次；由当前轮次造化签加权随机选出一名修士，获得池中全部资源。
- 无有效造化签时，奖池保留到下一轮。
- 开奖由读取市坊或进行玩法时懒触发；无人在线时不会凭空运行后台任务，下一次访问时补开。

## 每日限制

- 总有效落注：30次。
- 大堂：30次。
- 雅间开设或参与：15次。
- 修为局：10次。
- 当日总落注达到20次后，每次落注至少间隔30秒。
- 创建玩家赌桌即占用一次雅间次数，用于防止反复开桌和取消刷接口。
