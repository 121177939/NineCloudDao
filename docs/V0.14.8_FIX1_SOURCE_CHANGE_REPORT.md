# V0.14.8 FIX1源码变更报告

## 根因

大堂玩法按钮把草稿设为`fish_shrimp`后调用`renderCasinoPanel()`。该函数重绘前会执行`captureCasinoUiDrafts()`，从旧页面隐藏字段`houseGame=spirit_dice`重新写回草稿，导致刚选择的鱼虾灵局被覆盖，页面看起来没有反应。

## 修复

在调用重绘前，先把旧页面隐藏字段`houseGame`同步为新选择，再执行`renderCasinoPanel()`。

## 边界

- 仅修改`app.js`玩法切换顺序。
- CACHE12升级为CACHE13。
- 不修改数据库、RPC、概率、赔率、玩家庄、荷老、造化池与鱼虾结算。
