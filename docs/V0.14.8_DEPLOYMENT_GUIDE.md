# V0.14.8部署指南

## 顺序

1. 备份生产数据库和当前V0.14.7源码。
2. 执行`database/V0.14.8/202607281620_v0148_precheck.sql`，确认全部为true。
3. 执行`database/V0.14.8/202607281630_v0148_fish_shrimp_mobile_casino.sql`。
4. 执行`database/V0.14.8/202607281640_v0148_check.sql`，确认权限、RPC和CACHE12均正常。
5. 完整覆盖上传`NineCloudDao_GitHub_Upload_V0.14.8_FINAL.zip`内容。
6. 等待GitHub Pages工作流全部通过，再用无痕窗口和手机真机验收。

## 必验

- 页面版本为V0.14.8 CACHE12。
- 赌坊B线布局仍为2×2、1×4、2×2、双卡与奖池双列。
- 鱼虾页顺序为紧凑设置、开盘、选择下注、历史、明细、规则。
- 荷老局灵石/修为、玩家局灵石均能下注。
- 封盘后禁止下注，离开再返回仍能看到服务端下注与结算。
- 命中法印发光，历史与明细不重复桌别。

## 限制

本交付未连接生产Supabase，也未在Android/iOS真机执行端到端测试。部署前静态门禁不能替代生产备份和真机验收。
