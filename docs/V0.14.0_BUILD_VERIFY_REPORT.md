## 已验证的关键契约

- 页面名称为“市坊”，不出现独立“市场”页面标题。
- 市坊首页有天命榜、赌坊、珍宝阁三个入口。
- 手机底部导航不再重复显示独立天命榜。
- 九霄界闻对事件正文进行HTML转义。
- 赌坊大堂每一局已结算胜负均有数据库触发器入口。
- 雅间只有状态转为`settled`且存在胜者时播报。
- 退款、取消与失败事务不通过胜负触发器写入。
- 世界事件表开启RLS，普通认证玩家没有直接写权限。
- 私有发布函数和后台裁决接口未授权给authenticated。
- 事件来源唯一约束防止同一结算重复播报。
- 触发器异常被隔离，不反向回滚核心玩法。
- Pages制品不包含SQL、Python、文档、工具、Git元数据或压缩包。

## 验证边界

本地验证不能替代以下外部验收：

- V0.14.0 SQL在目标Supabase真实执行。
- check与data audit在真实数据上的结果。
- GitHub Actions线上build/deploy成功。
- Android、iPhone、平板和桌面真机测试。
- 使用真实账号完成胜局、败局、突破和机缘后的实际播报。
- 后台service_role接口与未来管理后台的联调。

因此本报告只证明交付包的源码、静态SQL契约、渲染模拟和Pages构建正确，不声称数据库或线上站点已经部署。
