# V0.11.3运行时热修复说明

## 故障表现

角色进入游戏后出现：

```text
updateProgressionDisplay is not defined
```

页面随后显示“重新连接”，修炼界面刷新中断。

## 根因

V0.11.2将机缘改为自动结算时，修改 `bindProgressionActions()` 附近代码，误将与机缘选择无关的 `updateProgressionDisplay()` 一并删除；`updateLiveCultivationDisplay()`仍每250毫秒调用该函数，因此浏览器抛出ReferenceError。

## 修复

从真实V0.11.1基线恢复该函数，并保留V0.11.2自动机缘逻辑。函数负责：

- 读取云端突破门槛；
- 根据实时修为计算0—100%的突破进度；
- 更新完整与紧凑进度条；
- 达到门槛时启用突破按钮；
- 未达到门槛时显示尚缺修为。

## 防复发措施

`tools/verify_release.py`新增显式运行时符号检查：发布前必须同时存在函数调用和函数定义。JavaScript语法检查只能发现语法错误，不能发现这种ReferenceError，本版因此增加了额外静态契约检查。
