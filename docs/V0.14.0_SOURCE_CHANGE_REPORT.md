# V0.14.0源码变更报告

## 基线

- 来源：V0.13.1 FINAL权威GitHub包。
- 前端：原生HTML、CSS、JavaScript。
- 后端：Supabase Auth、PostgREST、PostgreSQL RPC、RLS。

## 前端变更

- 页面正式名称统一为“市坊”。
- 原独立天命榜入口并入市坊首页。
- 市坊首页新增天命榜、赌坊、珍宝阁三入口。
- 天命榜与赌坊作为市坊子视图打开，保留返回市坊和浏览器返回逻辑。
- 珍宝阁建立占位页，未开放交易。
- 新增九霄界闻列表、空状态、停用状态、失败状态、相对时间和手动刷新。
- 九霄界闻每20秒刷新；赌场数据仅在赌坊子页每10秒刷新。
- 大堂赌局结算成功后立即并行刷新赌场与九霄界闻。
- 手机底部导航移除重复的独立天命榜项，仍保持每页最多六项。

## 数据库变更

- 新增 `world_event_settings`。
- 新增 `world_events`，保留角色名称快照与唯一来源约束。
- 新增认证只读RPC `get_world_events_v1(integer)`。
- 新增私有发布函数和突破、机缘、赌场触发器。
- 新增service_role后台接口 `admin_publish_account_erasure_v1`。
- 广播触发器全部带异常隔离，播报失败不会回滚核心玩法。

## 未包含

- 珍宝阁商品、寄售、拍卖、玩家转账。
- 玩家聊天或付费喇叭。
- 管理后台页面本体。
- 世界模拟tick、地图、秘境和战斗。
