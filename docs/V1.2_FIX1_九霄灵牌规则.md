# V1.2 FIX1 九霄灵牌规则

## 房间

- 天、地、玄、黄最多四间开放房。
- 创建后20分钟仍未开始首局，服务器自动关闭。
- 牌九最多9名玩家；大牌九玩家局最多8名，老何局最多7名玩家加老何。

## 模式

- 老何固定庄：玩家与老何逐一比较，100:100等额输赢。
- 玩家随机抢庄：抢庄者中安全随机；无人抢庄时从全部参战者随机。庄家预存最大责任资金。
- 玩家开船：赌注进入公共池，按牌力由高到低赔付；同牌力按赌注比例分配不足余额。

## 牌局

- 传统32张牌九骨牌，服务端安全洗牌。
- 牌九：本人一张明牌、一张暗牌；6秒选择10/50/100倍，超时默认10倍。
- 大牌九：先看本人两张牌，选倍后获得四张私牌；30秒组合，头牌不得强于尾牌；先亮弱头10秒，再亮强尾。

## 资金

- 老何庄只复用 `casino_bankroll_v1`，不另建资金池。
- 玩家局每笔确认赌注收取2.5%手续费，整数余数在房间内累计。
- 赌注与手续费合计不得超过确认前可用资源的30%。
- 玩家庄系统零兜底；结算使用单事务和请求ID幂等。
