# V0.15.0 部署指南

## 部署顺序

1. 备份当前 GitHub 仓库和 Supabase 数据库。
2. 在 Supabase SQL Editor 执行：
   1. `database/V0.15.0/202607281900_v0150_precheck.sql`
   2. `database/V0.15.0/202607281910_v0150_fish_continuous_bet_world_feed_exclusion.sql`
   3. `database/V0.15.0/202607281920_v0150_check.sql`
3. 解压并完整覆盖上传 `NineCloudDao_GitHub_Upload_V0.15.0_FINAL.zip` 的内容。
4. 确保 `.github/workflows/deploy-pages.yml` 与 `.nojekyll` 一并上传。
5. GitHub Pages Source 使用 `GitHub Actions`。
6. 等待 Actions 的 build 与 deploy 均成功。

## 验收

- 连续点击同一法印时，按钮不出现“落注中”，也不会被临时禁用。
- 点击鱼五次后，界面可显示待提交累计金额，并最终计入“我的下注”。
- 鱼、虾等不同法印可交替点击。
- 封盘后按钮才禁用。
- 九霄界闻中不新增鱼虾灵局下注或结算消息。
- 灵骰问道、气运龟卜原有界闻仍正常。

## 回滚

1. 部署 V0.14.9 CACHE15 完整源码。
2. 执行 `database/V0.15.0/202607281930_v0150_rollback.sql`。
3. 回滚不会删除鱼虾下注记录。
