# V0.14.8 B模块接入说明

## B模块原始范围

B线模块只修改`app.js`和`styles.css`，无SQL。内容为赌坊手机端排版优化：总览2×2、导航1×4、入口2×2、庄家双卡、奖池双列和整体字号/留白压缩。

## 核验结果

- 基线锁定为V0.14.7_AB5。
- 上传基线压缩包SHA256与B清单完全一致。
- B候选文件哈希、补丁应用、正式名称和继承测试均有原始证据，保存在`B_INTEGRATED_V0148/`。
- 禁止名称“墨玉赌坊”“未来玩法一/二”未进入正式源码。

## A线追加内容

A线在B候选页面基础上新增鱼虾灵局、数据库公共轮次与用户确认的极简鱼虾页面。这些属于V0.14.8 A线升级，不属于B原始数据库范围。
