# V0.13.1 GitHub Pages部署热修复

## 事故

2026-07-26，V0.13.0提交 `30d2a0e` 的GitHub Actions运行 #28 在“Verify V0.13.0 release”步骤以exit code 1终止。

## 根因

GitHub Desktop覆盖复制不会删除仓库中已跟踪但新包未包含的旧文件。仓库仍保留 `tools/audit_v0120_fix1.py`，而V0.13.0验证器要求该文件必须不存在。干净解压目录没有该文件，因此本地通过；真实覆盖升级仓库仍有该文件，因此线上失败。

## 修复

1. 验证器允许无害旧文件残留，只要求活动工作流不引用旧入口。
2. 用兼容桩覆盖三个常见旧工具入口。
3. 只从白名单构建新的 `.pages-site` 目录。
4. Pages只上传该目录，数据库、文档、工具和旧残留文件均不部署。
5. Actions拆为可定位的独立步骤。
6. 固定Python 3.13.5和Node.js 24。
7. 使用Node 24兼容的checkout/setup actions。

## 数据库

本版无SQL。不要重跑V0.13.0迁移。
