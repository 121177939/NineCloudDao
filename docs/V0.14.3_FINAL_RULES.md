# V0.14.3最终规则

1. 市坊中的天命榜入口保留，进入后展示修为榜、财富榜、战力榜三个切换项。
2. 每次进入天命榜页面，默认选择修为榜，并自动向数据库读取一次最新修为榜。
3. 修为榜与财富榜互相切换时，必须重新读取目标榜单最新数据。
4. 榜单页面不显示“刷新天命”或任何手动刷新按钮。
5. 修为榜继续使用既有`get_destiny_ranking_v1`，原排序规则不变。
6. 财富榜按唯一统一灵石余额从高到低排序；余额相同时依次比较大境界、小境界、修为、角色创建时间和角色ID。
7. 财富榜只显示角色名、境界、命格、道统世代与灵石余额，不返回账号或内部标识。
8. 战力榜可以点击切换，但只显示“暂未开放”，不调用数据库。
9. 修为榜和财富榜继续保留每次50名的“继续观榜”分页。
10. 本版不修改任何玩家资产或既有玩法结算。
