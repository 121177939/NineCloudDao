## 部署前

1. 备份Supabase数据库。
2. 保留当前V0.11.10 FIX3仓库副本。
3. 不要再执行V0.12.0初稿 `202607260800_v0120_market_casino.sql`。

## 数据库顺序

### 情况A：从未执行过V0.12.0初稿

1. 执行 `202607260830_v0120_fix1_precheck.sql`。
2. 确认12项全部为 `PASS`。
3. 执行 `202607260830_v0120_fix1_market_casino.sql`。
4. 执行 `202607260830_v0120_fix1_check.sql`。
5. 确认27项全部为 `PASS`。

### 情况B：已经成功执行过V0.12.0初稿

1. 不要运行初稿回滚。
2. 先执行FIX1预检查。
3. 直接执行FIX1主SQL；它会保留现有赌桌与彩池数据、补齐新表与字段，并删除初稿危险函数。
4. 执行FIX1检查SQL，确认27项全部为 `PASS`。

任何一步出现红色错误都应停止，不继续上传前端，并保留完整错误文字和行号。

## 紧急文件

- `emergency_disable.sql`：停止创建和参与新对局；已有封存赌契仍可结算，未应局赌桌仍可返还。
- `resume.sql`：恢复新对局。
- `rollback.sql`：先备份赌场表并返还所有open/sealed赌注，再移除V0.12.0赌场结构。
