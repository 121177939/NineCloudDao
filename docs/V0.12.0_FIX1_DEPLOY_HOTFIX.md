# V0.12.0 FIX1 GitHub Pages 部署热修复

## 故障原因

旧 GitHub 上传包中的 `.github/workflows/deploy-pages.yml` 执行：

```text
python3 tools/verify_release.py --root . --mode github --require-node
```

但上传包没有包含 `tools/verify_release.py`，因此验证步骤直接以退出码 1 结束。
完整源码中的旧验证器还与当前 `release_config.json` 结构不兼容，会触发 Python 异常。

## 修复方式

工作流改为执行当前版本已经随包发布且本地通过的两项专项验证：

```text
python3 tools/audit_v0120_fix1.py .
node tools/test_market_render_v0120_fix1.js .
```

同时将 Checkout 固定为稳定的 `actions/checkout@v4`。

## 影响范围

- 仅修改 GitHub Pages 工作流。
- 不修改游戏逻辑。
- 不修改赌场规则。
- 不修改数据库和 SQL。
- 不需要重新执行任何迁移 SQL。
