# V0.14.9 部署指南

1. 解压`NineCloudDao_GitHub_Upload_V0.14.9_FINAL.zip`。
2. 将包内全部文件（包括`.github`、`.nojekyll`）完整覆盖到仓库根目录。
3. V0.14.9没有新增SQL；已经执行V0.14.8鱼虾迁移时不要重复执行。
4. 在GitHub仓库 Settings → Pages 中确认发布源为 **GitHub Actions**。
5. 推送到`main`后查看`Deploy NineCloudDao to GitHub Pages`。
6. build成功后deploy会自动执行。
7. 页面底部应显示`0.14.9`，核心资源请求包含`0149-cache15`。

若仍失败，请点开红色的build任务，复制第一个失败步骤的完整日志；仅凭Summary页无法判断仓库权限或Pages设置问题。
