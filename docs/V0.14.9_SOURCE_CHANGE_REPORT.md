## GitHub Pages

- 工作流使用build与deploy两任务。
- build生成`.pages-site`并校验后上传Pages artifact。
- deploy只负责部署artifact，并设置`pages: write`与`id-token: write`。
- 移除固定Python/Node安装步骤及无效的setup-node输入，减少早期构建失败。
