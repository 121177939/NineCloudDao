## 修复闭环

- 5%公证费用全部进入对应造化彩池。
- 同招流局全额返还且不抽水。
- 玩家B应局后300秒揭晓，一局定胜负。
- 公开赌桌1800秒无人应局自动返还，创建者可主动取消。
- 修为局元婴期开放、最低50,000、单注最高可损失修为20%。
- 修为输钱只在当前大境界内重新匹配小境界，并重算基础吐纳。
- 双彩池、造化签、两小时开奖、中奖发放和开奖记录形成完整闭环。
- 总落注30次、雅间15次、修为10次与20次后的30秒冷却已由数据库执行。
- 角色级事务锁防止并发重复开桌或同时应局多桌。
