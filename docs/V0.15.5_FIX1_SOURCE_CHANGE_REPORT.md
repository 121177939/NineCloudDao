# V0.15.5 FIX1 CACHE27 源码变更报告

## 目标

将洞府主景从抽象元神式法阵修正为具有幽静、洞窟、灵脉、石台、仙府、隐修和经营感的独立视觉空间。

  - 洞府主景增加岩壁拱洞、钟乳轮廓、灵脉、仙府灯影和石台结构。
  - 洞府标题改为“洞天幽居 · 灵脉自运”。
  - 保留六建筑经营入口、真实库存、资源条与洞府操作。
- `styles.css`
  - 移除洞府大型旋转圆环动画。
  - 新增洞窟岩壁、壁龛、地面、灵脉流光、石台、雾气和灯火样式。
  - 增加低动态与 `prefers-reduced-motion` 兼容。
- PWA
  - 客户端构建号升级为 `v0155-fix1-cache27`。
  - Service Worker 缓存提升为 CACHE27。

## 数据库改动

无业务数据库结构改动。SQL 只更新 `jiuxiao_app_release_control` 的发布名称、缓存纪元和公告文案。
