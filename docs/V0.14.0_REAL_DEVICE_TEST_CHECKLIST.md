# V0.14.0真机测试清单

## 通用

- [ ] Android、iPhone、平板和桌面浏览器均可登录。
- [ ] 页脚显示Web Alpha 0.14.0。
- [ ] 旧PWA升级后无白屏和旧版缓存残留。

## 市坊首页

- [ ] 页面标题为“市坊”。
- [ ] 三个入口同排且不溢出：天命榜、赌坊、珍宝阁。
- [ ] 九霄界闻在320px宽屏仍可阅读。
- [ ] 空状态、停用状态和网络错误状态可正确显示。
- [ ] 点击刷新界闻不会重复绑定事件或重复请求。

## 子页面

- [ ] 天命榜加载、分页/刷新与返回市坊正常。
- [ ] 赌坊原有大堂、雅间、造化池功能无回归。
- [ ] 珍宝阁仅显示占位，不允许交易。
- [ ] 手机系统返回键和页面“返回市坊”行为一致。
- [ ] 再次点击底部“市坊”可回到首页。

## 播报

- [ ] 大堂赌赢产生一条“赌运亨通”等胜局播报。
- [ ] 大堂赌输产生一条“时运不济”等败局播报。
- [ ] 同一赌局不会重复播报。
- [ ] 雅间有胜负时同时写明胜者与败者。
- [ ] 取消、超时返还和未结算赌契不播报胜负。
- [ ] 造化池开奖播报一次。
- [ ] 天品机缘正向与反噬文案正确。
- [ ] 元婴以上突破重大结果文案与真实结算一致。

## 安全

- [ ] authenticated不能直接插入或修改world_events。
- [ ] authenticated不能调用私有发布函数或后台裁决函数。
- [ ] 九霄界闻写入异常不会导致赌场或突破事务失败。
