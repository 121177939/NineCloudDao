# V0.14.3源码变更报告

## 前端

- `app.js`新增`rankingBoard`状态和财富榜状态。
- 榜单区域由原来的统计与手动刷新按钮改为三项标签切换。
- 进入天命榜时强制选择修为榜并自动读取。
- 切换修为榜或财富榜时自动读取目标榜单。
- 删除榜单60秒定时刷新和手动刷新事件。
- 新增战力榜占位页。
- 市坊入口副标题更新为“修为 · 财富 · 战力”。

## 样式

- `styles.css`新增三等分榜单标签、选中状态、未开放标记和战力榜占位样式。
- 手机端三项标签保持同排，不横向溢出。

## 数据库

- 新增`get_wealth_ranking_v1(integer,integer)`只读RPC。
- RPC只向`authenticated`开放，`anon`无执行权。
- 排序读取唯一统一灵石库存，不执行余额归一化、扣除或发放。
- 发布控制提升到`V0.14.3 CACHE7`。
