# V0.14.2部署指南

## 前置

数据库有效链应至少包含：V0.14.0 FIX2/FIX3、V0.14.1主迁移、FIX2、FIX3、FIX4、FIX5、FIX6、FIX7、FIX7A。FIX8禁止执行。

## 顺序

1. 备份数据库。
2. 执行`database/V0.14.2/202607270900_v0142_world_feed_strict_newest.sql`一次。
3. 检查末尾全部`ok=true`。
4. 覆盖GitHub仓库。
5. GitHub Actions完成版本校验、JS语法、SQL静态审计、界闻排序模拟、Pages制品验证后部署。
6. 打开市坊，连续制造两条不同类型界闻，确认后一条始终显示在第一位。

## 回滚边界

V0.14.2只新增序号字段并替换读取RPC。紧急情况下可恢复V0.14.0 FIX2中的`get_world_events_v1`，但旧版会重新启用置顶优先排序，不建议长期回滚。
