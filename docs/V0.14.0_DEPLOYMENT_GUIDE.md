# V0.14.0部署说明

## 一、部署前

1. 确认当前源码为V0.13.1 FINAL。
2. 确认V0.13.0迁移已部署；未部署时先按V0.13.0说明完成，不能把V0.14.0当作替代迁移。
3. 对Supabase数据库做可恢复备份。
4. 不执行任何已废弃的V0.12.0 FIX3或早期赌场初稿。

## 二、执行SQL

在Supabase SQL Editor中依次执行：

1. `202607261430_v0140_precheck.sql`
2. `202607261430_v0140_bazaar_world_events.sql`
3. `202607261430_v0140_check.sql`
4. `202607261430_v0140_data_audit.sql`

主迁移成功后不要重复执行。检查结果中的所有核心项必须为true，`duplicate_sources`和`invalid_empty_content`应为0。

## 三、上传前端

使用GitHub上传包覆盖仓库根目录并推送main。等待Actions的build和deploy两个job完成。

## 四、线上验收

- 页脚版本为0.14.0。
- 导航名称为“市坊”，不存在“市场”页面标题。
- 市坊首页显示天命榜、赌坊、珍宝阁和九霄界闻。
- 天命榜与赌坊能进入并返回市坊。
- 珍宝阁显示筹备占位，不发生交易请求。
- 完成大堂胜局和败局后，分别出现对应界闻且只出现一次。
- 低境界普通突破不刷屏；高境界重大结果按规则出现。
- 天品机缘正负结果能生成对应文案。

## 五、缓存

部署后完全关闭旧PWA，必要时清理站点数据。缓存名应为 `nine-cloud-dao-v0.14.0`。
