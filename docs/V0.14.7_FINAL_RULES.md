# V0.14.7最终规则

## 功法书与藏经架
- 普通主修/辅修功法和五种专属道卷由机缘收入洞府藏经架，不自动学习、不自动装备。
- 普通功法未学时消耗一本研习；已学时消耗一本参悟并转化原品级传承点。
- 专属本命与异命均可收藏，只有当前命格匹配的本命道卷可以研习。

## 机缘展示
- 命书固定显示品阶、机缘名称、故事正文以及本次具体所得或惩罚。
- 天机推演结果区显示具体修为、灵石、临时效果、功法书或道卷。
- 黄品、玄品、地品沿用默认色；天品、仙品、专属统一高阶强调色。

## 洞府物品
- 可使用的堆叠物品可选择合法整数数量；批量操作在数据库同一事务内完成。

## 玩家庄
- 统一灵石达到500万即可申请，无需财富榜第一。
- 每次上庄最多2小时，到期后必须重新申请。
- 玩家庄存在时，闲家可自由选择荷老或玩家庄。
- 玩家庄只接受灵石且不限下注金额；闲家中奖时，毛利润扣5%佣金后先扣玩家庄，不足由荷老补足。
- 玩家庄局不进入造化池；荷老系统庄仍严格执行FIX7A。
