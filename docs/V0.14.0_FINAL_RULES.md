# V0.14.0最终规则

1. 游戏内正式名称为“市坊”，不使用“市场”作为页面名称。
2. 市坊首页上方固定为天命榜、赌坊、珍宝阁；下方为九霄界闻。
3. 珍宝阁本版只占位，不开放任何资产交易。
4. 九霄界闻是服务器只读事件流，不是玩家聊天频道。
5. 赌坊大堂每一局成功结算的胜或负都播报；这是本版明确规则，不设置小额门槛。
6. 取消、退款、平局全额返还、等待应局和事务失败不算胜负，不播报。
7. 文案必须使用结算后的实际数值；修为奖励被硬上限截断时不得虚报。
8. 客户端不得创建、修改、删除世界事件。
9. 后台删除违规账号前可通过service_role发布天道裁决；正常注销默认不广播。
10. 播报系统是旁路，任何播报异常不得回滚核心结算。
