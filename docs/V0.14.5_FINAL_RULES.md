# V0.14.5最终规则

## 机缘V4
- 在线与离线统一每5分钟一次；离线最多72小时、864次。
- 普通五品与专属均使用完整触发/结果池；专属趋吉五功法混池、20%本命、异命100灵石与+2%保底不变。
- 修为奖励按当前小境界完整需求动态计算；修为损失不低于当前小境界起始线；灵石不得扣为负数。
- 临时修炼速度效果中，V4正面取最强、负面取最强后相抵；其他系统继续原逻辑。

## 功法
- 原12门主修、原效果、首次奖励、重复传承点完整保留。
- 新增12门辅修；主修槽1个、辅修槽2个；辅修熟练速度50%，实际功法效果不打折。
- 一级为完整基础效果，每升一级增加一级基础效果10%。
- 重复获得只增加获得次数与传承点，不重复叠加首次永久奖励。

## 玩家庄
- 只修改玩家庄，系统庄FIX7A不变。
- 闲家胜：本金100%返还，毛利润95%发给闲家，5%由当局玩家庄保留。
- 闲家败：下注本金100%归玩家庄，不另收佣金。
- 玩家庄佣金不入造化池、不发造化资格。
