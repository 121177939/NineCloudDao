# V0.15.0 源码变更报告

## 基线

- 源码基线：V0.14.9 CACHE15 自适应正式版。
- 数据库基线：V0.14.8 鱼虾灵局及既有 V0.14.1 FIX7A、V0.14.2 界闻、V0.14.4 综合规则。

## 前端变更

- 删除鱼虾法印按钮的 `落注中…` 忙碌锁，不再因单次请求等待而阻止继续点击。
- 增加全局串行落注队列。同一轮次、同一庄家、同一资源、同一法印的快速点击在 120ms 窗口内合并金额。
- 不同法印可交替连续点击；后台按队列顺序提交，避免并发响应乱序覆盖状态。
- 法印卡显示“待提交 +金额”，状态栏显示队列中的点击次数。
- 只有轮次进入封盘、开盘或结算阶段时才禁用法印。
- 保留 V0.14.9 自适应宽度、手机三列、SVG法印、命中发光和现有结算页面。

## 数据库变更

- 重定义 `world_event_from_house_game_v0140()`，在函数入口显式排除 `game_code='fish_shrimp'`。
- 灵骰问道、气运龟卜和天命豹子界闻逻辑保持不变。
- 发布控制提升为 `V0.15.0 CACHE16`。
- 不修改鱼虾赔率、概率、下注表、结算函数和历史数据。
