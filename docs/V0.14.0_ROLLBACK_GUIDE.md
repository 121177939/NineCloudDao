# V0.14.0回滚说明

## 优先方案：紧急停用

执行 `202607261430_v0140_emergency_disable.sql`。该操作立即停止新界闻写入和前端显示，不影响突破、机缘与赌坊结算。

恢复时执行 `202607261430_v0140_resume.sql`。

## 安全回滚

执行 `202607261430_v0140_rollback.sql`：

- 删除V0.14.0触发器和公开RPC。
- 删除相关函数。
- 保留 `world_events` 与 `world_event_settings`，供审计和后续恢复。
- 不修改V0.13.0修为、突破或赌场核心结构。

随后回退前端到V0.13.1。若需要彻底删除历史界闻表，应在确认不再需要审计后由数据库管理员单独处理，正式回滚脚本不会自动删表。
