# V0.14.0数据库变更日志

## 新增表

### world_event_settings

控制总开关、突破、机缘、赌坊、后台播报开关，保留天数和最大读取条数。

### world_events

保存全服界闻。核心字段包括事件类型、等级、角色名称快照、最终文案、结构化元数据、来源表/来源键、置顶、公开和过期时间。

唯一约束 `(source_table, source_key, event_type)` 防止网络重试或触发器重复写入同一事件。

## 新增RPC

- `get_world_events_v1(integer)`：authenticated可执行，只读最近事件。
- `admin_publish_account_erasure_v1(text,text,text,text)`：仅service_role或数据库管理员可执行。

## 新增触发器

- `cultivation_records`：重大突破结果。
- `opportunity_v3_results`：天品、仙品、专属，以及地品涉险结果。
- `casino_house_games`：每一局已结算大堂胜负。
- `casino_duels`：雅间赌契结算，合并播报胜者和败者。
- `casino_draws`：造化池开奖。

退款、取消、等待应局、平局返还和失败事务不会生成胜负播报。

## 安全边界

- 两张表启用RLS并撤销普通角色直接权限。
- 普通玩家不能插入、修改或删除世界事件。
- 客户端不能指定最终文案、事件等级或输赢结果。
- 角色删除后 `actor_character_id` 置空，名称快照和历史文案保留。
