# V2.1.1 CACHE117 装备背包状态与升品破境修复

- 装备主列表的 `location/is_locked` 不再被并行强化状态的旧值覆盖。
- 穿戴/卸下后的强制刷新会等待并发刷新完成后再次拉取，避免旧缓存。
- 打开“孔位 / 升品 / 破境”及提交操作前，客户端通过 SQL247 实时装备状态 RPC 再次确认数据库位置。
- 孔位操作成功后同步刷新装备主状态。
- SQL247 修复造化升品玉、乾坤破境石成功时读取不存在 `ring_element_multiplier` 的错误，改用 `bequipment01_value` 权威数值函数。
- 穿戴中的装备仍禁止孔位洗炼/升品/破境；背包装备才允许操作。
