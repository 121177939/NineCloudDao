# SQL246 / CACHE116 装备孔位洗炼规则修复

本次修复确认了旧规则与实际需求不一致：SQL239/SQL243 的兵魄/护道会保留旧孔位等级，因此 Lv10 使用兵魄后只能换属性、等级不变。

CACHE116 / SQL246 正式规则：

- 兵魄道玉（武器）/护道灵玉（防具、戒指）：未锁孔同时随机属性类型与等级。
- 百炼玄铁：只随机未锁且已有属性孔位的等级，属性类型不变。
- 锁孔：属性与等级都保护；最多3孔。
- 付费防空转：有其它等级可选时排除原等级；兵魄/护道优先排除原属性组合；若整次没有任何实际变化则事务回滚，不扣材料、锁玉、灵石。
- 灵石成本、材料成本、背包专用限制、百炼GM总开关均保持不变。

执行前提：SQL245 R2 已安装。若未安装，会直接报 `SQL246_REQUIRES_SQL245_R2_FIRST`，且不会产生任何改动。

成功标志：`SQL246_GATE_PASSED`，下一迁移号为 SQL247。
