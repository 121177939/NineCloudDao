# SQL247 R2 / CACHE117

修复两个装备运行时问题：

1. 卸下/穿戴后客户端并行缓存可能保留旧 `location`，导致背包装备被误判为非背包。SQL247新增只读实时装备状态RPC，CACHE117每次打开淬炼和提交操作前都会重新核对数据库中的 `location/is_locked`。
2. 造化升品玉、乾坤破境石旧RPC直接读取生产品级记录中不存在的旧字段，成功判定后会报字段不存在。SQL247改为调用既有权威 `bequipment01_value(template_id, grade_code)`。
3. R2修复R1门禁误报：R1的 `pg_get_functiondef()` 检查把函数体说明注释里的旧字段名当成真实代码引用。R2先剥离 `--` 注释，再验证可执行代码。

SQL247要求SQL246已安装。若SQL246尚未执行，请按“SQL246→SQL247”顺序执行。

上一份SQL247 R1如果在门禁阶段报错，则事务在COMMIT前已回滚，直接完整执行R2即可，不需要回滚，也不占SQL248。
