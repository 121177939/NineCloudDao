# V2.1.1 CACHE110 装备孔位洗炼交互重做

- 五种材料由大卡片改为紧凑材料栏。
- “孔位属性”主页面不再显示长提示；点击标题弹出规则说明。
- 孔位单列显示：□ ① 属性 +最终值（LV.x），最多显示当前实际开放孔，最高8孔；空孔写“空”；LV.10整条红字。
- 武器按钮：使用兵魄×1 / 使用百炼×1；防具与戒指：使用护道×1 / 使用百炼×1。
- 孔锁最多3个。锁定孔位属性类型与等级都不变化；每次刷新按锁孔数消耗定灵锁玉。
- 兵魄/护道只刷新未锁孔属性类型；已有孔LV保留，空孔首次生成时随机LV。
- 百炼改为一次随机重炼整件装备所有未锁且已有属性孔的LV；属性类型不变，空孔不参与。
- 兵魄/护道/百炼操作不再刷新整个页面，只原地更新孔位与材料数量并保留锁孔勾选。
- 装备跃迁说明移除“成功率由GM控制”字样，只显示当前实际成功率。
- GM仍为ADMIN9 R22；百炼开关继续有效。
