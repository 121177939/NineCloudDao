# 九霄问道 V2.1.1 CACHE107 世界BOSS准备按钮热修

## 修复原因
CACHE106 的 `b-world-boss01.js` 在“锁定快照并准备”和“复制口令”点击监听器中，把 `click` 事件对象当作按钮元素读取 `dataset`，导致点击后在调用RPC之前直接抛出JavaScript异常，玩家看起来就是“无反应、无提示”。

## 修复
- 两处监听器统一使用 `event.currentTarget` 获取真实按钮。
- “锁定快照并准备”恢复调用 `set_world_boss_member_ready_bwboss01`。
- 服务端RPC若返回错误，继续进入现有toast错误提示链。
- “复制口令”同步修复同类问题。
- 不改SQL233世界BOSS战斗逻辑，不改SQL234全天开放/GM读取规则。
