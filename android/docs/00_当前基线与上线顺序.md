# V2.1.1 CACHE113 当前基线与上线顺序

1. 先执行 SQL243 升级SQL；SQL本身会做结构前置检查，失败会整事务中止。
2. 发布网页 V2.1.1 CACHE113 与 Android 2001413 / 2.1.1-cache113；Pages R3 与 Android Release R6 发布方式不变。
3. 使用 ADMIN9 R23 → 数据库 → 一键检查数据库；先执行安全清理 dry-run，确认保护项与候选数量。
4. 实机确认登录、修炼、机缘、市场、世界事件、牌九、装备/世界BOSS等核心功能。
5. 最后执行 SQL243 制度门禁；必须看到 `SQL243_GATE_PASSED` 才把该数据库视为 CACHE112 正式基线。

SQL243不依赖旧 release_control 显示必须等于CACHE111；只用真实表/字段/函数/Cron结构做基线检查，避免历史显示值滞后造成误判。
