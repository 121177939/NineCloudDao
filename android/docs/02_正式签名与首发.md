# 正式签名与首发

## 重要规则

Android 只允许使用相同包名和兼容签名的 APK 覆盖升级。第一版公开 APK 使用哪把签名密钥，之后所有在线更新就必须继续使用那把密钥。

不要把密钥、密码或 `signing.properties` 提交到 GitHub。

## 创建密钥

可以在 Android Studio 中使用：

Build → Generate Signed App Bundle or APK → APK → Create new

建议：

- 密钥有效期至少25年
- 单独做两个加密备份
- 记录 alias，但不要把密码写入源码

## 本地配置

1. 把密钥放到项目根目录，例如 `release.keystore`。
2. 复制 `signing.properties.example` 为 `signing.properties`。
3. 填写真实信息。
4. 执行：

```bash
./gradlew clean assembleRelease
```

输出一般位于：

`app/build/outputs/apk/release/app-release.apk`

如果没有 `signing.properties`，release 产物不会得到你的正式签名，不可作为用户更新链的首发包。
