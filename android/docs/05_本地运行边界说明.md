# 本地运行边界说明

## 已本地化

以下内容完全打入 APK：

- HTML页面
- CSS样式
- JavaScript游戏逻辑
- 图片资源
- `config.js`
- CACHE93装备强化界闻与V2.0.1客户端改动

应用启动不依赖 GitHub Pages，也不会把远程网页嵌入应用。

## 仍需联网

当前游戏源码采用 Supabase 作为权威后端，因此以下功能仍需互联网：

- 注册与登录
- 角色存档读取和写入
- 装备强化等RPC结算
- 九霄界闻与实时数据
- 宗门、赌场、秘境和其他服务器权威功能

“本地运行”在这里表示客户端源码和静态资源本地执行，不表示把生产数据库和服务器函数搬进手机。若要做到完全离线单机，需要另行重写账号、数据库、RPC、实时订阅和存档体系，不能仅靠Android项目封装完成。
