# 项目静态验收

本项目交付前执行了以下离线检查：

- 项目关键文件完整性检查
- Android Manifest 与全部资源 XML 解析
- 10个游戏 JavaScript 文件语法检查
- 4个 Python 工具脚本语法检查
- Gradle 启动器 JAR 内容与启动流程测试
- 本地游戏资源同步脚本幂等性检查
- APK 游戏资源中无 PWA Service Worker、远程网页入口或 GitHub Pages 工作流
- WebView 禁止 `file://` 文件访问、Content访问、File URL跨域和混合内容
- 更新流程包含版本号、包名、SHA-256和APK签名校验
- ZIP路径安全与SHA-256清单检查

当前执行环境没有 Android SDK 和外网依赖下载能力，因此未在交付环境内完成
`assembleDebug` 或 `assembleRelease` 的真实 Android 编译。项目已包含 GitHub Actions；
上传仓库并配置签名 Secrets 后，工作流会执行完整 Android 构建。首次发布前还应在
Android Studio 中完成真机登录、存档、牌九实时连接、装备强化和应用内升级测试。
