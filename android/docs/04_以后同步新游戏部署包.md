# 以后同步新的游戏部署包

收到新的《九霄问道》完整部署包后，在项目根目录执行：

```bash
python3 tools/sync_game_assets.py /路径/新的完整部署包.zip
```

脚本会：

1. 安全检查 ZIP 路径。
2. 定位 `public/index.html` 与 `public/app.js`。
3. 把运行文件同步到 `app/src/main/assets/game/`。
4. 排除 GitHub Pages 工作流、构建工具和 `.pages-site` 验收副本。
5. 移除 PWA Service Worker 更新入口。
6. 注入 Android 本地运行标识。

同步后还需要手工更新：

- `gradle.properties` 的版本号
- `app/build.gradle.kts` 中的 `GAME_BUILD_ID`
- `MainActivity.java` 关于页面中的游戏基线文字
- `release/release-notes.txt`

最后执行：

```bash
python3 tools/validate_project.py
./gradlew clean assembleDebug
```
