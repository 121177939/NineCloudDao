# 九霄问道 B线模块：功法书与洞府藏经架

**状态：READY_FOR_A（待A线核验接入）**  
**唯一基线：V0.14.6_AB4 / Web Alpha V0.14.6 CACHE10**

本模块把机缘中的功法获得方式由“立即学习/立即生效”改为“获得功法书或专属道卷，收入洞府藏经架，由玩家主动处理”。

## 已实现规则

- 24门普通主修/辅修功法：机缘掉落后只获得对应功法书×1，不自动学习、不自动装备、不立即发放首次奖励。
- 同名书自动堆叠为×N。
- 未学普通功法：消耗一本“研习”，学会1级，首次研习奖励此时一次性发放；仍不自动装备。
- 已学普通功法：消耗一本“参悟”，按原规则获得传承点：玄40、地50、天65、仙80。
- 5门专属功法：本命和异命都作为专属道卷入库，不再回收异命，也不再补偿100灵石。
- 只有当前命格对应的本命专属道卷能研习；异命道卷只能收藏。
- 本命专属研习后为1级，不自动放入专属槽。
- 已学本命专属的额外道卷继续堆叠留存，本模块不自动转化、不自动升级。
- 专属保底继续保留：异命时本命权重+2个百分点，本命时重置20%。
- 在线/离线机缘、品级概率、普通功法掉率、首次奖励内容、功法数值、玩家庄5%佣金、V0.14.6命书明细均保持原基线规则。

## 交付内容

- `database/`：预检、主迁移、后检、紧急停用、恢复、回滚，以及一键顺序执行SQL。
- `patches/`：基于V0.14.6_AB4精确生成的 `app.js` / `styles.css` 补丁。
- `source/candidate/`：补丁应用后的候选共享文件。
- `tests/`：补丁应用、UI标记、SQL静态审计及原基线门禁测试。
- `docs/`：最终规则、数据模型和测试边界。

## 接入顺序

1. 核验 `BASELINE_REFERENCE.json` 与基线文件SHA256。
2. 数据库先执行 `00_precheck.sql`。
3. 执行 `10_technique_book_library.sql`。
4. 执行 `30_postcheck.sql`，确认所有 `ok=true`。
5. 对V0.14.6_AB4应用两个共享文件补丁。
6. A线更新正式版本号、缓存号和发布清单后，复跑全部门禁。

不要将本模块直接套到其他版本，也不要再次执行旧的V0.14.5 B模块。
