# 最终规则：功法书与专属道卷

## 普通功法

1. 机缘命中普通主修或辅修功法时，获得同名功法书×1并收入洞府。
2. 获得书时不学习、不装备、不提供功法效果、不发首次奖励。
3. 同名书合并数量。
4. 未学时消耗一本研习：学会1级，首次研习奖励发放一次，不自动装备。
5. 已学时消耗一本参悟：玄40、地50、天65、仙80传承点；不重复发首次奖励。

## 专属功法

1. 专属趋吉仍在原5门池中抽取。
2. 本命和异命都获得对应专属道卷×1，全部收入洞府。
3. 异命不回收、不补偿100灵石。
4. 只有当前命格匹配的本命道卷可研习。
5. 异命道卷不能学习、不能装备、没有效果，只能收藏。
6. 本命研习后为1级，不自动装备。
7. 已学本命后，额外同名道卷继续堆叠留存，本模块暂不提供专属道卷参悟。
8. 异命抽取后本命概率+2个百分点，本命抽取后重置20%。
