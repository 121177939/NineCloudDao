# B线开发从这里开始

你收到的是《九霄问道》完整基线 **V0.15.4_AB11_CACHE23**，不是增量升级包。

1. 完整解压本包作为工作目录。
2. 阅读 `CURRENT_BASELINE.json`、`AB_CONTROL/` 和本目录。
3. 只实现用户指定的新模块，不直接接入正式版。
4. 不修改版本号、CACHE23、Pages工作流或既有正式SQL。
5. 新SQL放在模块自己的 `SQL_CANDIDATE/` 中，必须可审计、可重复评估并提供回滚/停用方案。
6. 交付时打包完整模块给A，由A负责冲突处理、合并、升版和最终完整包。

特别注意：灵石不在 `player_characters.spirit_stones`，统一位于 `character_inventory`，必须调用现有统一灵石函数。
