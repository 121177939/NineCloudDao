# 九霄问道 Web Alpha 0.11.5

东方文字修仙挂机养成 Web 游戏，使用静态 HTML/CSS/JavaScript、Supabase 与 GitHub Pages。

## V0.11.5 FINAL 内容

本版以 V0.11.1 真实源码为基线，汇总并修正 V0.11.2—V0.11.5 的功能链：

- 300 条黄、玄、地、天、仙五品自动机缘；
- 在线每 5 分钟、离线每 20 分钟，离线最多补结算 1 条；
- 角色自动趋吉或涉险；
- 修炼页机缘轮：中心“机”字与内圈静止，外圈和金色光点缓慢旋转；
- 最近一次机缘结果摘要；
- 机缘即时修为、灵石、永久/临时修炼加成、天机迟滞、功法奖励与洞府资源映射实际结算；
- 正式机缘功法按一级完整效果、每级线性增加一级基础效果的 10% 生效；
- 五本命格专属功法、独立专属槽、专属升级和实际修炼加成；
- 恢复 `updateProgressionDisplay()`，修复突破进度运行时错误；
- 修复手机端机缘轮越界；
- 保留 V0.11.1 的仙历、寿元、轮回、功法 V2、洞府、天命榜、红尘、宗门和命书。
