## V2.2.0 CACHE122

- 功法页拆分为 **修炼 / 攻伐 / 护体**；灵根、命格首页仅显示摘要，点击弹出完整说明。
- 现有全部功法继续作为修炼功法，原获取方式、原掉率、五槽和专属槽全部保留。
- 新增攻伐10本、护体10本，各只能装备1本；无参悟境界门槛，不赠送初始攻防功法。
- 新功法采用同名残卷：10张合1完整道卷；同品其它残卷可混合5换1指定残卷。
- 机缘攻防残卷总概率=当前普通功法实际掉率×20%；秘境独立玄12%/地8%/天4%/仙2%；世界BOSS普通20%天品，困难25%天品+5%仙品。
- 秘境未结算残卷属于风险资产：战败按本轮总数 `floor(50%)` 随机原物转移；同一胜者/败者6小时第1次100%、第2次25%、第3次起0。
- 普通修炼、专属、攻伐、护体四类升级灵石默认全部为旧成本 **10倍**，四类倍率由ADMIN9 R33独立调整，最终扣费以服务端为权威。
- 功法战斗效果使用固定 `effect_code` 服务端引擎，天命榜、秘境PVP、秘境妖兽、世界BOSS全部必须真实生效并写入战报；SQL254不允许半接入上线。
- 快照规则：天命榜开战锁定；秘境入场锁定；世界BOSS“锁定快照并准备”时锁定；中途GM改值只影响下一场。
- 高阶传承：服务器首次有人参悟某本天品/仙品攻防功法时，SQL254会在现有九霄界闻表结构兼容时写入“天地有感”；界闻兼容失败不阻断功法核心事务。
- 取消《九霄问剑录》，仙品攻伐采用《九霄凌绝经》，不再额外强化天生剑心。
