# 九霄问道 Web Alpha 0.8.0

GitHub Pages 正式发布文件。

## 本版内容

- 新增功法体系 V2：品质、层数上限、服务器权威熟练度、传承点、正式槽位和功法组合。
- 功法品质统一为凡、黄、玄、地、天、仙六档，不同品质拥有不同层数上限、精进成本、重复获得收益和熟练速度。
- 主修固定 1 槽，辅修固定 2 槽；切换槽位由数据库 RPC 处理。
- 主修按 100% 速度增长熟练，辅修按 50% 速度增长；熟练与传承点合计达到 100 才能精进下一层。
- 重复获得功法改为增加“获得次数”和“传承点”，不再生成可叠加的永久修炼速度效果。
- 新增四种组合：同源共鸣、三法归一、形意相济、三象轮转。
- 时间规则保持现实 1 天 = 仙历 12 年；命书继续显示最新 100 条。

## 数据库要求

必须先完成 V0.7.0 数据库升级，再执行：

`database/V0.8.0/202607240014_technique_system_v2.sql`

随后执行：

`database/V0.8.0/202607240014_check.sql`

升级后理论数据库基线为 47 张公共业务表、35 个公共函数。

SQL 成功并检查通过后，才可以上传 V0.8.0 网页文件。
