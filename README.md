# 九霄问道 V1.7.4 CACHE50｜GitHub轻量部署包

本版本是纯前端界面修复，基于V1.7.3 CACHE49。

## 修复内容

- 随身装备背包固定常驻在元神页面，始终显示6×6格。
- 删除装备背包的“打开”“关闭”、遮罩和弹窗入口。
- 点击空装备槽时只滚动到常驻背包，不会打开新窗口。
- 洞府继续只保留原生洞天主景和单一6×6洞府储物格。
- 洞府顶部资源条不再重复显示“统一灵石”；统一灵石仍保留在全局余额和洞府储物物品格中。
- 装备详情、批量分解、装备匣等操作弹窗仍可正常关闭。

## 部署

本版本无SQL。数据库应已完成V1.7.2的102 FIX1与103检查。

1. 解压本包。
2. 覆盖GitHub仓库根目录，保留仓库自身`.git`目录。
3. 确认隐藏目录`.github`一并提交。
4. 推送`main`并等待GitHub Actions的`build`与`deploy`成功。
5. 手机端完全关闭旧页面后重新打开；CACHE50会清理旧缓存。

`B_HANDOFF/`仅供B开发交接，Pages白名单构建不会发布该目录。
