# 九霄问道 Web Alpha V0.14.1

> V0.14.1 FIX1：修复赌坊自动刷新导致“修为”回跳为“灵石”的前端状态问题；无需新增SQL。

本版在V0.14.0 FIX2/FIX3基础上统一灵石系统并重构万运博弈楼。

## 核心变化

- 全游戏只使用`item_definitions.code='spirit_stone'`这一种灵石。
- 升级时自动合并历史绑定/非绑定灵石行，机缘奖励会立即进入实际可用余额。
- 机缘、洞府兼容奖励、赌坊、宗门、普通功法和专属功法统一使用同一余额。
- 市坊进入赌坊后先选择大堂、贵宾雅间或全服造化池，再选择灵石/修为、快捷倍数或自定义赌注。
- 取消每日场次、每日修为局和30秒冷却限制。
- 每笔有效赌注全额进入对应全服造化池；取消、超时返还和同招流局不入池。
- 每名角色每期每种资源池只有一份等权资格；重复游玩增加池额但不增加个人权重。
- 开奖先从参与者中等概率抽取候选人，再以40%判定命中；60%未中则全额滚存。
