# 九霄问道 Web Alpha 0.9.0

《九霄问道》是基于静态 HTML/CSS/原生 JavaScript 与 Supabase 的东方文字修仙挂机游戏。

## V0.9.0：洞府经营

本版在 V0.8.0 功法体系 V2 基础上新增道统洞府：

- 洞府绑定 `lineage_id`，角色转世后仍保留建筑、资源和炼丹进度。
- 新增灵蕴、灵草、灵矿三种洞府资源。
- 新增灵脉、灵田、矿室、丹炉、库房五座建筑，当前最高 10 级。
- 资源按 Supabase 数据库服务器时间在线/离线结算，离线收益上限为现实 72 小时。
- 新增聚气丹、聚灵香、悟道茶三种炼丹配方；同一时间只允许一炉炼丹任务。
- 丹炉每提升一级缩短 6% 炼制时间，最低保留基础时间的 35%。
- 储物与物品使用入口整合到“洞府”页面。
- V0.7.0 的现实 1 日 = 仙历 12 年、寿元、死亡与轮回继续有效。
- V0.8.0 的主修 1 槽、辅修 2 槽、功法熟练、传承点与组合继续有效。
- 命书继续显示最新 100 条，最新记录在最上方。

## 数据库执行顺序

V0.9.0 依赖 V0.8.0 **修正版**功法迁移。若之前出现：

`relation "v080_legacy_equipped" does not exist`

必须先执行修正版 V0.8.0 SQL并通过 V0.8.0 检查，然后再执行：

1. `database/V0.9.0/202607240015_cave_management.sql`
2. `database/V0.9.0/202607240015_check.sql`

升级后的理论数据库基线为 **55 张公共业务表、42 个公共函数**。数据库检查完成后，才能发布 V0.9.0 网页文件。

## 功法说明

功法页面会直接显示数据库中每门功法的名称、类别、属性、品阶、固定效果与介绍。由于初始功法目录保存在已部署的阶段 1 数据库中，本包不会伪造未获取到的功法名称。详细机制见：

- `docs/V0.9.0_TECHNIQUE_INTRODUCTION.md`
- `database/V0.9.0/202607240015_technique_catalog_readonly.sql`
