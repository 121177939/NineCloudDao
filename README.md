## 灵骰规则

- 大、小各50%，结果不读取玩家选择或两边下注量。
- 普通非豹子毛利润1倍。
- 普通豹子全服1/80，毛利润3倍。
- 天命豹子全服1/5000，毛利润34倍。
- 赢局从毛利润提取5%入造化池。
- 败局下注10%入造化池、90%由天道回收。
- 固定押任意一边的长期理论期望约-0.999%。
