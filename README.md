# 九霄问道 Web Alpha 0.11.0

东方文字修仙挂机养成Web游戏，使用静态HTML/CSS/JavaScript、Supabase与GitHub Pages。

## 本版核心

- 新增“宗门”页面，提供4个默认宗门；
- 未入门角色可以拜入宗门，或消耗5000灵石开山立派；
- 新增外门、内门、核心、真传、长老、掌门六级职位；
- 新增贡献、共享宗门库藏、每日事务与每日俸禄；
- 新增聚灵阵、传功殿、执事堂、库藏阁四类共享建筑；
- 宗门建筑与职位会提供服务器权威修炼加成；
- 新增全体门人共享的宗门史，并同步关键事件到角色命书；
- 保留红尘录、天命榜、洞府、功法V2、现实1日=仙历12年和命书最新100条。

部署时必须先执行V0.11.0数据库升级和检查，再上传GitHub运行文件。
