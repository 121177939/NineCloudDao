# 九霄问道 V1.7.2 CACHE48｜GitHub轻量部署包

本包可直接解压覆盖GitHub仓库根目录。必须连同隐藏目录`.github`一起提交。

## 本版

- 随身装备背包由30格提升为36格，固定6×6；
- 手机端背包不再变成5列或4列；
- 洞府只保留原生一套6×6储物格；
- 洞府装备直接嵌入原生空格，空间不足时进入“装备匣”；
- 删除装备模块重复的洞府格和背包/洞府双页签；
- 老何牌九公平随机与页面规则保持不变，没有加入隐藏胜率控制。

## 数据库与部署

数据库已完成101号时：

`102背包36格与CACHE48门禁 → GitHub部署 → 103升级后检查`

SQL不放在本GitHub部署包中，位于独立SQL包。

## GitHub Pages

1. 解压本包并覆盖仓库根目录；
2. 提交全部文件，包括`.github/workflows/deploy-pages.yml`；
3. 推送`main`；
4. Settings → Pages → Source确认使用GitHub Actions；
5. 等待`build`和`deploy`均成功。

`B_HANDOFF/`用于继续发给B协作，构建白名单不会把它发布到正式网站。
