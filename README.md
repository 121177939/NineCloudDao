- 天命榜页面顶部改为`修为榜 / 财富榜 / 战力榜`三项切换。

- 修为榜和财富榜每次互相切换时自动重新读取，不再提供手动刷新按钮。
- 财富榜按唯一统一灵石余额从高到低排列。
- 战力榜暂未开放，仅显示占位说明，不调用数据库。
- “继续观榜”分页仍保留。
