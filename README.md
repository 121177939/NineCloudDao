# 九霄问道 V1.8.3 CACHE80

当前公开游戏基线：`v1-8-3-cache80-perf1`。

## PERF1 在线负载优化

本版本以生产中的CACHE78为唯一基线，不采用此前未部署的CACHE79赌场移除草案。牌九和鱼虾玩法仍保留；每秒牌九Cron保持停用。

### 修改前

- 会话心跳每5秒。
- 修为同步每15秒。
- 机缘结算每10秒。
- 世界事件和天谕每10秒。
- 洞府、功法、红尘、宗门每60秒在后台自动读取，部分RPC还会写数据库。
- 网页切到后台后，多数网络定时器仍会继续触发。

### 修改后

- 会话心跳每30秒，网页隐藏时暂停。
- 修为与机缘云端结算每60秒；本地修为数字和倒计时仍实时显示。
- 世界事件和天谕每60秒；天道均衡每5分钟。
- 洞府、功法、红尘、宗门改为进入对应页面时按需刷新。
- 从后台返回时只刷新当前页面，15秒内自动合并重复的visibility/focus事件。
- 市坊只在玩家停留于市坊时刷新。

### 对玩家的效果

- 修为、机缘、洞府资源等最终总量不减少。
- 云端入账和通知最多比原来晚几十秒，返回游戏或进入页面时会统一补算。
- 页面点击、领取和切换更稳定，手机流量与耗电降低。
- 异地登录替换检测最多可能延迟到30秒；玩家进行其他云端操作时通常会更早被门禁发现。

## 保留规则

- CACHE78装备分解十倍、强化、异灵根仅基础道攻+8%、秘境和GM FIX5规则全部保持不变。
- 牌九与鱼虾前端、RPC和历史数据均未删除。

## 部署顺序

1. 保持当前`jiuxiao-paigow-v16-tick`任务为`active=false`。
2. 执行SQL176，固化Cron停用状态。
3. 部署本CACHE80公开文件。
4. 执行SQL177正式发布门禁。
5. 执行SQL178只读检查，确认`ok=true`。
