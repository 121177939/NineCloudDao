# 九霄问道 Web Alpha 0.10.0

东方文字修仙挂机养成Web游戏，使用静态HTML/CSS/JavaScript、Supabase与GitHub Pages。

## 本版核心

- 新增“红尘录”，每一世角色可结识6位九霄界NPC；
- NPC拥有姓名、称号、境界、性格、属性与人物介绍；
- 支持论道、赠礼、请教和挑衅；
- 支持师徒、道侣、金兰和仇敌关系；
- 特殊关系可提供修炼加成，交游事件同步写入命书；
- 冷却、数值变化和奖励均由Supabase服务器结算；
- 保留天命榜、洞府、功法V2、现实1日=仙历12年和命书最新100条。

部署时必须先执行V0.10.0数据库升级和检查，再上传GitHub运行文件。
