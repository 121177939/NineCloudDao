# 九霄问道 Web Alpha V0.13.1

V0.13.1是在 **V0.13.0 FINAL** 基础上的发布流水线热修复。游戏玩法与V0.13.0保持一致，不新增数据库表、字段或RPC。

## 本版修复

- 修复覆盖式更新后，旧版 `tools/audit_v0120_fix1.py` 残留导致验证器误判失败的问题。
- GitHub Actions改为分步验证，失败时可以直接看到具体失败环节。
- 固定Python 3.13.5与Node.js 24，避免Hosted Runner默认版本漂移。
- 使用Node 24兼容的官方Actions版本。
- 构建全新的 `.pages-site` 最小部署目录，只上传网页运行文件。
- 增加Pages制品清单、SHA256和独立制品验证。
- 增加覆盖升级模拟测试，专门模拟旧文件仍留在仓库的真实情况。

## 数据库

V0.13.1不需要执行新SQL。

- 已部署V0.13.0数据库迁移：不要重跑。
- 尚未部署V0.13.0数据库迁移：仍按V0.13.0部署说明执行一次。
- 旧V0.12.0 FIX3继续永久禁用。

## 发布

使用 `NineCloudDao_GitHub_Upload_V0.13.1_FINAL.zip` 覆盖仓库根目录。即使旧工具文件仍然存在，新工作流也只验证当前有效入口并仅部署 `.pages-site`。
