# 九霄问道 Web Alpha 0.7.0

GitHub Pages 正式发布文件。

## 本版内容

- 新增服务器权威仙历：现实 1 天推进游戏 12 年，现实 2 小时推进 1 个游戏年。
- 仙历、角色年龄和寿元由 Supabase 数据库服务器时间结算，前端仅负责显示。
- V0.7.0 从数据库迁移执行时刻开始计时，不追溯扣除 V0.6.6 之前的寿元。
- 角色寿元耗尽后自动标记为陨落，旧角色停止修炼、机缘和突破，并保留命书。
- 新增转世流程：保留原道统、世代编号递增，灵根与命格重新由服务器生成。
- 转世可选择一项前世遗泽：悟性 +2、气运 +2 或心境 +2。
- 命书继续显示最新 100 条，最新记录在最上方。

## 数据库要求

本版必须先执行：

`database/V0.7.0/202607240013_time_lifespan_reincarnation.sql`

再执行：

`database/V0.7.0/202607240013_check.sql`

升级后预期数据库基线为 43 张公共业务表、26 个公共函数。
