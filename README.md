# 九霄问道 Web Alpha V0.14.2 CACHE6

> 当前玩法基线仍为 **V0.14.1 FIX7A**；V0.14.2专门修复九霄界闻排序与刷新。FIX8不属于有效部署链。

## 本版修复

- 所有九霄界闻严格按新消息排序，任何新消息都会顶掉旧消息。
- 旧的`is_pinned`仅保留为历史样式字段，不再拥有排序优先权。
- 新增`feed_sequence`单调序号，避免突破、赌坊等消息在同一时间写入时顺序不稳定。
- 前端再做一次严格倒序，默认拉取30条，每10秒自动刷新。

## 部署

当前数据库应已完成V0.14.1 FIX7A。然后只执行一次：

`database/V0.14.2/202607270900_v0142_world_feed_strict_newest.sql`

确认末尾12项检查全部为`true`，再用V0.14.2完整包覆盖GitHub仓库。

## 当前赌坊规则（继承FIX7A）

- 大、小各50%，开奖结果不读取玩家选择或两边下注量。
- 普通非豹子毛利润1倍。
- 普通豹子全服1/80，毛利润3倍。
- 天命豹子全服1/5000，毛利润34倍。
- 赢局从毛利润提取5%进入造化池。
- 败局下注10%进入造化池，90%由天道回收。
- 固定押任意一边的长期理论期望约为-0.999%。
