# 九霄问道 V1.7.3 CACHE49｜GitHub轻量部署包

本版本是前端稳定性补丁，基于V1.7.2 CACHE48。

## 修复内容

- 洞府不再偶尔出现“随身背包在上、洞府储物在下”的第二套版式。
- 洞府始终保持原生洞天主景、资源、单一6×6储物格及操作栏。
- 随身装备背包移动到元神页独立入口，以6×6弹窗打开。
- 装备在洞府中的存放仍直接占用原生洞府空格，溢出时进入装备匣。

## 部署

本版本无SQL。数据库应已完成V1.7.2的102 FIX1与103检查。

1. 解压本包。
2. 覆盖GitHub仓库根目录，保留仓库自身`.git`目录。
3. 确认隐藏目录`.github`一并提交。
4. 推送`main`并等待GitHub Actions的`build`与`deploy`成功。
5. 手机端完全关闭旧页面后重新打开；CACHE49会清理旧缓存。

`B_HANDOFF/`仅供B开发交接，Pages白名单构建不会发布该目录。
