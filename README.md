# 九霄问道 Web Alpha V0.14.0

V0.14.0基于 **V0.13.1 FINAL** 升级，正式将原“市坊 · 万运博弈楼”整理为公共功能总入口，并新增服务器只读的“九霄界闻”。游戏内名称统一使用 **市坊**。

## 本版内容

- 市坊首页新增三个入口：天命榜、赌坊、珍宝阁。
- 天命榜与赌坊进入独立子视图，返回后回到市坊首页；底部导航继续高亮市坊。
- 珍宝阁建立正式占位入口，本版不开放物品交易。
- 新增九霄界闻，显示最近20条全服重大事件。
- 接入元婴及以上重大突破、跌境、修为损失、身死道消与高品机缘播报。
- 赌坊大堂每一局已结算胜负均播报；雅间结算同时播报胜者与败者；造化池开奖单独播报。
- 预留仅service_role可调用的“天道裁决”后台播报接口。
- 九霄界闻失败采用旁路隔离，不允许反向回滚突破、机缘或赌坊结算。

## 数据库部署

V0.14.0包含新SQL，必须先备份数据库，并严格按顺序执行：

1. `database/V0.14.0/202607261430_v0140_precheck.sql`
2. `database/V0.14.0/202607261430_v0140_bazaar_world_events.sql`
3. `database/V0.14.0/202607261430_v0140_check.sql`
4. `database/V0.14.0/202607261430_v0140_data_audit.sql`

已成功执行主迁移后不要重复执行。紧急停用、恢复与安全回滚脚本也位于同一目录。
