# 九霄问道 V1.8.3 CACHE78

当前公开游戏基线：`v1-8-3-cache78-decompose10-uifix1`。

## CACHE78 装备分解器源十倍

- 黄、玄、地、天、仙品默认分解产出分别为 **10 / 20 / 40 / 80 / 160 器源**。
- 强化一次仍按原品级基数消耗：**黄1 / 玄2 / 地4 / 天8 / 仙16**。
- 因此默认分解一件装备约可提供 **10次同品级强化尝试**；每次仍需灵石并承担失败毁装风险。
- ADMIN9 R11 FIX5可以直接调整每个品级的分解产出；不会同步修改强化消耗。
- 强化概率、灵石消耗、属性增幅、孔位和失败毁装规则不变。

## 元神手机端文案修复

- 异灵根规则仍为：风、冰、雷只增加境界基础道攻8%。
- 元神右侧“加成”卡片改为短文案，例如“基攻+8% · 戒指+4%”，不再显示大段规则说明。
- 道御、生机、身法以及装备、强化、功法和戒指数值不参与异灵根8%计算。

## 部署顺序

当前生产环境已经完成CACHE77与SQL164 FIX1—166时：

1. 执行SQL167。
2. 部署本CACHE78公开游戏文件。
3. 使用ADMIN9 R11 FIX5调整各品级分解产出。
4. 执行SQL168正式发布门禁。
5. 执行SQL169只读检查，确认`ok=true`。

## 保留系统

- 装备强化最高+10及强化特效规则保持不变。
- 背包固定6×6、品级单字角标和手机端装备图标位置保持不变。
- 秘境奖励、牌九、五行克制与异灵根基础道攻规则保持CACHE77现状。
- GM仅本地使用，不得部署到公开站点。
