# 九霄问道 V1.7 CACHE46｜GitHub轻量部署包

这是从 `V1.6 FIX1 CACHE45` 整理得到的正式GitHub部署包。游戏功能、牌九事件驱动架构和全部已确认规则保持不变，本版重点是减少重复交付文件。

## 部署

1. 解压本ZIP。
2. 用解压后的全部内容覆盖GitHub仓库根目录；必须保留隐藏目录 `.github`。
3. 不要把ZIP本身上传到仓库，不要删除仓库自身的 `.git`。
4. 提交并推送到 `main`。
5. 仓库 `Settings → Pages` 的发布来源设为 `GitHub Actions`。
6. Actions中应先通过 `build`，再执行 `deploy`。

## 数据库

本包不重复携带SQL。数据库已执行到96号时，从配套轻量接管资料包执行：

`97_V1.7_CACHE46_轻量交付发布门禁.sql → GitHub部署 → 98_V1.7_CACHE46_升级后检查.sql`

## 包内保留内容

- 正式网页运行文件；
- GitHub Pages工作流；
- 一个可移植构建检查脚本；
- 当前版本与基线元数据；
- `B_HANDOFF/`：可直接发给B的当前基线、任务单模板、交付规范和禁止事项；
- 本说明和校验值。

旧SQL、历史说明、测试日志、B候选源码、截图和旧版本交付物不再重复放入本包。`B_HANDOFF/`只包含小体积协作文档，Pages白名单构建不会发布该目录。
