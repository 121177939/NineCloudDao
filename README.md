# 九霄问道 Web Alpha 0.11.10-fix1

本修复版以V0.11.9为数据库基线，修正V0.11.10主SQL把`spirit_roots.id`、`realm_stages.id`误写成UUID的问题；这些查询表ID实际为`smallint`。

## 新规则

- 元婴期以下突破失败不触发死亡、跌境、清空修为或伤势，但仍累计失败补偿。
- 角色最低不得因突破失败跌到元婴期以下。
- 同一恢复周期只允许触发一次“大境界跌落”；再次抽中转为无损失败。
- 成功回到首次大跌境前所在的大境界后，解除大跌境锁。
- 原有失败补偿不变：首次失败+10个百分点，之后每次+30个百分点；补偿介入后的最终成功率最高80%。
- 灵根、境界基础吐纳和天道最后乘算规则保持不变。
