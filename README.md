## 当前规则重点

- 战力榜高、低战力角色可以互相挑战，不能挑战自己。
- 每名玩家每日最多主动挑战20次，每场有效挑战后全局冷却20分钟。
- 可以在冷却结束后重复挑战同一个角色。
- 低战力击败高战力：转移败者当前小境界起点以上进度的1%。
- 高战力击败低战力或同战力胜利：转移0.5%。
- 修为转移向下取整，不允许败者跌破当前小境界起点。
- 胜者当前修为与战利修为暂存的总增加量，严格等于败者实际扣除量。
- 挑战趣味界闻写入前端实际读取的 `public.jiuxiao_world_events`，并回填历史挑战界闻。
