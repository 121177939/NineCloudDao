# 九霄问道 Web Alpha 0.12.0-fix1

本版以 **V0.11.10 FIX3 前端 + V0.11.10 FIX1/FIX2 数据库** 为基础，正式加入“市坊·万运博弈楼”。

## 本版内容

- 大堂庄家局：灵骰问道、气运龟卜。
- 贵宾雅间：玩家暗选灵拳或五行灵拳，第二人应局后封存五分钟，一局定胜负。
- 灵石与修为均可下注；修为局元婴期开放，单次最低50,000，最高为当前大境界可损失修为的20%。
- 修为输钱可在当前大境界内回退小境界，但绝不会跌出当前大境界。
- 胜负局抽取总赌注5%，全部进入对应造化彩池；平局全额返还且不抽水。
- 每两小时开启一次灵石/修为造化池，完成有效对局可获得造化签。
- 每日总落注30次，大堂30次、雅间15次、修为局10次；20次后每次间隔30秒。
- 公开赌桌30分钟无人应局自动返还，也可由创建者主动取消。

## 数据库部署

1. 运行 `database/V0.12.0/202607260830_v0120_fix1_precheck.sql`。
2. 预检查全部通过后运行 `database/V0.12.0/202607260830_v0120_fix1_market_casino.sql`。
3. 再运行 `database/V0.12.0/202607260830_v0120_fix1_check.sql`，确认全部为 `PASS`。

V0.12.0初稿 `202607260800_v0120_market_casino.sql` 已废弃，不得继续部署。FIX1主SQL可直接覆盖修复已经执行过初稿的数据库。
