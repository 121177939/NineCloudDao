# 九霄问道 V1.7.7 CACHE56｜九霄灵牌 UI02 与四倍率版

正式源码基线：V1.7.6 CACHE55。数据库最低基线：V1.7.6 CACHE55 / SQL 109。

## 本版内容

- 保留 V1.7.6 的灵骰与牌九多人性能、Realtime、阶段推进、私牌遮罩、服务端结算及全部既有代码。
- 最后接入 `B-PAIGOW02-UI02`，正式牌局画面与UI02预览结构对齐。
- 牌九选倍调整为 `10 / 30 / 50 / 100`，超时默认仍为10倍。
- 既有“赌注与手续费合计不得超过开局余额30%”规则保持不变。
- 不修改灵骰、鱼虾蟹、玩家庄100:97.5、联合庄、奖池和其他牌九结算规则。

## 强制部署顺序

1. 执行 `110_V1.7.7_升级前检查.sql`；所有 `ok` 必须为 `true`。
2. 执行 `111_V1.7.7_牌九10_30_50_100倍率兼容.sql`；任何报错立即停止。
3. 重新克隆正式GitHub仓库到全新目录；保留 `.git`，用本ZIP全部内容覆盖仓库根目录，包括 `.github`、`tools`、`B_HANDOFF`。
4. 不要Merge旧分支，不要再次运行任何会重新生成 `b-paigow01.html` 的旧模板。
5. 提交 `Deploy V1.7.7 CACHE56` 并推送 `main`；确认GitHub Actions的 `build` 与 `deploy` 两个Job均绿色。
6. 前端成功上线后执行 `112_V1.7.7_CACHE56_正式发布门禁.sql`。
7. 最后执行 `113_V1.7.7_CACHE56_升级后检查.sql`；所有 `ok` 必须为 `true`。
8. 手机彻底关闭旧网页后重新打开；如作为PWA安装，先完全退出再启动。

SQL 111会在事务内识别生产牌九函数与CHECK约束中的旧 `10/50/100` 白名单并改为 `10/30/50/100`。若线上函数结构与历史基线不一致，它会报错并回滚，不会猜测覆盖未知函数。
