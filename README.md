# 九霄问道 Web Alpha 0.11.3

东方文字修仙挂机养成Web游戏，使用静态HTML/CSS/JavaScript、Supabase与GitHub Pages。

## 本版性质

V0.11.3是V0.11.2的前端运行时热修复版本，不新增玩法、不改变数据库结构。

## 修复内容

- 恢复V0.11.2制作过程中误删的 `updateProgressionDisplay()`；
- 修复进入游戏后出现 `updateProgressionDisplay is not defined` 并中断修炼界面刷新的问题；
- 恢复境界突破进度文字、进度条和突破按钮的实时刷新；
- 发布验证新增关键运行时函数完整性检查，避免仅靠JavaScript语法检查漏掉“调用存在、函数定义缺失”的错误；
- 保留V0.11.2的300条五品自动机缘、5本命格专属功法与此前全部系统。

## 数据库

V0.11.3不执行新SQL，数据库继续沿用V0.11.2迁移后的基线：75张公共业务表、61个数据库函数。

- 已经成功执行V0.11.2迁移：直接覆盖V0.11.3前端文件。
- 尚未执行V0.11.2迁移：先执行 `database/V0.11.2/202607250020_auto_opportunity_v3.sql` 并通过检查，再部署前端。
- 永久禁止执行废弃文件 `202607240019_auto_opportunity_v2.sql`。
