# 九霄问道 Web Alpha V0.14.1 FIX7 CACHE4

> 当前玩法基线为V0.14.1 FIX7；CACHE4继续负责旧页面缓存与PWA更新。

本版在V0.14.0 FIX2/FIX3基础上统一灵石系统并重构万运博弈楼。


## FIX7天命豹子期望值热修复

- FIX6的豹子归入大小规则保持不变，玩家仍只押大或小。
- 普通结果与普通豹子押中均按净赔率1倍结算。
- 对应大小的豹子出现后，以9/275（约3.27%）判定是否成为天命豹子。
- 天命豹子净赔率34倍；固定押一边时实际触发率为1/2200。
- 按押100计算，长期平均净变化为-1，赌场优势约1%，不再能靠固定押一边稳定盈利。
- 天命豹子会进入九霄界闻单独播报。

## FIX6灵骰豹子规则热修复

- 灵骰只提供“大”“小”两种押注，不再要求单独押豹子。
- 3—10点为小，11—18点为大；豹子同样按总点数归类。
- FIX6原规则曾让所有对应豹子直接34倍；FIX7已改为普通豹子1倍，仅天命豹子34倍。
- 大堂每局5%入池规则保持不变。


## FIX5突破感悟热修复

- 修复角色跌落小境界或大境界后，界面与服务端只在再次冲击“原始目标”时才应用天劫感悟的问题。
- 现在恢复途中每一次突破都使用全部累计感悟：每丝固定增加5个百分点，最终成功率最高80%。
- 感悟仍绑定最初目标，真正抵达目标后才清零；已有的感悟数量会直接生效，无需修改角色数据。
- 部署SQL：`database/V0.14.1/202607270100_v0141_fix5_breakthrough_insight_route.sql`。

## CACHE1/CACHE2/CACHE3/CACHE4缓存热修复

- 页面核心资源使用构建编号查询参数，避免同名旧JS/CSS继续命中缓存。
- Service Worker对导航和JS/CSS/Manifest采用网络优先，离线时再使用缓存。
- 新Worker立即激活、清理旧九霄问道缓存并接管已打开页面。
- 客户端每60秒读取Supabase发布代号；`cache_epoch`增加时自动清理缓存并重载。
- 首次部署建议执行`database/V0.14.1/202607270100_v0141_fix5_breakthrough_insight_route.sql`。

## 核心变化

- 全游戏只使用`item_definitions.code='spirit_stone'`这一种灵石。
- 升级时自动合并历史绑定/非绑定灵石行，机缘奖励会立即进入实际可用余额。
- 机缘、洞府兼容奖励、赌坊、宗门、普通功法和专属功法统一使用同一余额。
- 市坊进入赌坊后先选择大堂、贵宾雅间或全服造化池，再选择灵石/修为、快捷倍数或自定义赌注。
- 取消每日场次、每日修为局和30秒冷却限制。
- 大堂每一局成功结算的赌注都有5%进入对应全服造化池；赢局返还本金并发放扣除这5%后的赔率盈利，败局余下95%由天道回收。
- 贵宾雅间分出胜负时，胜者取回自己的本金并获得败者赌注的95%，败者赌注剩余5%进入造化池；取消、超时返还和同招流局不入池。
- 每名角色每期每种资源池只有一份等权资格；重复游玩不会增加个人中奖权重。
- 开奖先从参与者中等概率抽取候选人，再以40%判定命中；60%未中则全额滚存。
