## GM交付方式

ADMIN9网页控制台为**本地专用工具**，不随GitHub Pages发布。本公开部署包故意不包含：

- `gm-admin.html`
- `gm-admin.css`
- `gm-admin.js`
- `gm-operations.html`

生产部署顺序见完整交付包中的《部署说明_LOCAL_GM_R1.md》。
