# 九霄问道 V1.7.7 FIX1 CACHE57

## 本版内容

本版以已经完成R2数据库升级的 `V1.7.7 CACHE56` 为唯一母包，修复九霄灵牌正式运行页面与B预览/用户确认画面不一致的问题。

- 新增正式动态视觉层：`B-PAIGOW02-UI03-RUNTIME-PARITY`。
- 手机端新增紧凑工具栏、桌心阶段提示、沿桌席位及底部自家牌区。
- 手机端“本局概览、排名、动态、规则”改为点击“谱/讯”后打开的信息抽屉，不再默认占用牌桌。
- 保留10/30/50/100倍率。
- 保留V1.7.6多人性能、Realtime、阶段推进、私牌遮罩、资金、手续费及全部结算规则。
- 本版不修改牌九业务RPC或数据库Schema。

## 部署顺序

1. 在Supabase执行SQL包中的 `114_V1.7.7_FIX1_升级前检查.sql`，所有 `ok` 必须为 `true`。
2. 重新克隆GitHub仓库，保留 `.git`，用本部署包全部文件完整覆盖仓库根目录。
3. 不要运行任何旧页面模板或旧UI01/UI02 PATCH_ROOT。
4. 提交并推送GitHub，等待 Actions 的 `build` 和 `deploy` 全部成功。
5. 执行 `115_V1.7.7_FIX1_CACHE57_正式发布门禁.sql`。
6. 执行 `116_V1.7.7_FIX1_CACHE57_升级后检查.sql`，所有 `ok` 必须为 `true`。
7. 手机彻底关闭旧网页/PWA后重新进入；顶部或发布信息应显示 `V1.7.7 FIX1 CACHE57`。

## 手机牌桌按钮

- `房`：返回房间大厅。
- `谱`：打开玩法/牌局信息抽屉。
- `设`：刷新当前牌桌状态。
- `音`：音效尚未实现，当前禁用，避免伪造功能。
- `讯`：打开牌局信息抽屉。
- `推演`：刷新服务端权威牌桌状态。

## 强制规则

`b-paigow02-ui03.css` 必须是牌桌最后加载的视觉层。正式包生成后不得再运行旧模板重新生成 `b-paigow01.html`，否则UI03会被覆盖。
