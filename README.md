## V0.14.4 本次升级

- 财富榜第一且统一灵石严格超过500万的玩家可自愿接替荷老坐庄；玩家庄只接受灵石，零抽成、零入池。
- 修为赌局只能损失当前小境界内修为进度，可一次押上全部可动用修为，输光不降低任何大小境界。
- 贵宾赌契被接受后立即开奖结算，不再等待5分钟。
- 每丝天劫感悟除突破成功率+5个百分点外，额外使最终总修炼速度+10%。
- 管理后台ADMIN2的奖励、补偿或惩罚会给指定玩家生成一次性私人天道弹窗。
- V0.14.2界闻排序、V0.14.3三榜和FIX7A系统庄概率保持不变。

## 本版更新

- 天命榜页面顶部改为`修为榜 / 财富榜 / 战力榜`三项切换。
- 进入页面默认打开修为榜并自动读取一次最新数据。
- 修为榜和财富榜每次互相切换时自动重新读取，不再提供手动刷新按钮。
- 财富榜按唯一统一灵石余额从高到低排列。
- 战力榜暂未开放，仅显示占位说明，不调用数据库。
- “继续观榜”分页仍保留。

## 部署

1. 备份Supabase数据库，并确认线上已部署FIX7A、V0.14.2和V0.14.3。
2. 执行`database/V0.14.4/202607272200_v0144_player_house_casino_notice_insight.sql`。
3. 确认脚本末尾13项检查全部为`true`。
4. 使用管理后台时，再执行独立的V0.14.4 ADMIN2 SQL；后台HTML严禁公开部署。
5. 用V0.14.4完整源码覆盖GitHub仓库并等待Pages门禁通过。
