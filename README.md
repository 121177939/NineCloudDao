# 九霄问道 Web Alpha 0.11.7-fix1

## 本次修复

- “灵气环境”明细格保持V0.11.6原有UI，不再使用渐变底色、状态色或箭头。
- 格内仅显示：`灵气环境（天道福泽） ×5`、`灵气环境（大道均衡） ×1` 或 `灵气环境（天道阻滞） ×0.5`。
- 点击该格仍可查看天道规则弹窗。
- 修复天道系数只影响约1点/秒灵气基础值的问题。现在天道系数作用于完整自动修炼速度：×0.5约减半，×5约提升为五倍。

## 部署

1. 已执行V0.11.7主迁移后，执行 `database/V0.11.7/202607260200_v0117_fix1_full_heaven_multiplier.sql`。
2. 执行 `database/V0.11.7/202607260200_v0117_fix1_check.sql`，确认全部PASS。
3. 上传本包前端文件并清理PWA缓存。

东方文字修仙挂机养成 Web 游戏，使用静态 HTML/CSS/JavaScript、Supabase 与 GitHub Pages。

## V0.11.7 内容

本版以已经通过数据库8项PASS检查的 V0.11.6 FINAL 为直接基线。

- 新增“天道动态均衡机制”；
- 低于全服主流境界：天道福泽，灵气环境收益提高；
- 修为贴近全服主流：大道均衡，系数×1；
- 高于全服主流境界：天道阻滞，灵气环境收益衰减；
- 系数依次为：×5、×4、×3、×2、×1.2、×1、×0.8、×0.6、×0.5；
- 全服主流境界按同一世界在世修士的大境界序号平均值四舍五入计算；
- 天道系数只调整“灵气环境”收益，不会将功法、机缘等固定收益整体重复乘算；
- 修炼页可点击“灵气环境（天道状态）”查看完整天道说明和动态数据；
- V0.11.6机缘正负互斥、50/50基准、机缘深厚趋吉+5，以及此前所有系统继续保留。
