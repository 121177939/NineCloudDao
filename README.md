# 九霄问道 Web Alpha V0.13.0

本版从 **V0.12.0 FIX1 + Deploy Hotfix** 真实源码继续升级，重构突破失败、天劫感悟和修为境界上限。

## 核心规则

- 突破失败后的二次结果：身死道消0.5%、大境跌落5%、小境跌落8%、损失本次突破所需全部修为15%、损失一半30%、有惊无险41.5%。
- 只有大境跌落、小境跌落、全部损失和一半损失真正执行时，天劫感悟+1丝，原目标突破率+5个百分点。
- 有惊无险、死亡、元婴以下保护、大跌境锁和元婴下限保护不增加感悟。
- 最终突破成功率始终不超过80%。
- 当前修为最多达到下一境界门槛；圆满后在线、离线、机缘和赌场等来源均不能继续溢出。
- 升级时所有旧角色超额修为直接截断到当前门槛，超额部分不补偿，并写入私有审计表。
- 修为圆满时禁止参与修为赌场；灵石玩法不受影响。

## 数据库部署

1. 备份Supabase。
2. 执行 `database/V0.13.0/202607261300_v0130_precheck.sql`。
3. 全部PASS后执行 `202607261300_v0130_breakthrough_cultivation_cap.sql`。
4. 执行 `202607261300_v0130_check.sql`，确认34项全部PASS。
5. 查看 `202607261300_v0130_data_audit.sql` 的截断记录。
6. 再上传V0.13.0前端。

旧 `V0.12.0 FIX3` 不得执行，也不是本版前置条件。
