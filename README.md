# 九霄问道 Web Alpha 0.11.6

东方文字修仙挂机养成 Web 游戏，使用静态 HTML/CSS/JavaScript、Supabase 与 GitHub Pages。

## V0.11.6 内容

本版以 V0.11.5 FINAL 为直接基线，并保留 V0.11.1—V0.11.5 已完成系统。

- 300条黄、玄、地、天、仙五品自动机缘保持完整；
- 在线每5分钟、离线每20分钟，离线最多补结算1条；
- 气运50、心境50时，趋吉50%、涉险50%；
- 趋吉概率公式：`50 + (气运 + 心境 - 100) × 0.5`，限制在10%—90%；
- 机缘深厚：趋吉额外+5个百分点，并继续使地、天、仙、专属品级相对权重+10%；
- 趋吉只结算正面效果，涉险只结算负面效果；
- 取消固定天机迟滞，涉险持续时间读取正式机缘文本；
- 功法V2、洞府、天命榜、红尘、宗门、寿元轮回、普通功法与专属功法继续保留。
