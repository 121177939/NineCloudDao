# 九霄问道 V1.8.0 CACHE60

当前公开游戏基线：`v1-8-0-cache60-equipment-enhance1`。

## 本次正式更新

- 全游戏统一材料“器源”，旧“器源精粹”数量首次读取时原样继承。
- 黄、玄、地、天、仙品装备分解与每次强化消耗分别为 `1 / 2 / 4 / 8 / 16` 器源。
- 装备可强化至 +10；失败时装备、全部孔位内容、本次器源与灵石永久消失。
- 灵石按目标等级 `N × 100万`；成功率和属性倍率由服务端权威配置。
- 品级基础孔位为 `1 / 2 / 3 / 4 / 5`，+6、+8、+10各增加1孔。
- 玩家强化确认按钮为“我命由我不由天”，取消为“我再回去考虑考虑”。
- GM升级至 ADMIN9 R9，可调整强化概率并直接设置玩家单件装备强化等级。

## 数据库顺序

1. 执行 `143_V1.8.0_装备分解与强化系统_安装.sql`；
2. 部署本源码；
3. 执行 `144_V1.8.0_CACHE60_正式发布门禁.sql`；
4. 执行 `145_V1.8.0_CACHE60_升级后检查.sql`；
5. GM功能执行 `146_V1.8.0_ADMIN9_R9_装备强化管理.sql`；
6. 执行 `147_V1.8.0_ADMIN9_R9_升级后检查.sql` 与 `148_V1.8.0_CACHE60_ADMIN9_R9_当前状态总检查_只读.sql`。

紧急停用玩家强化使用 `149_V1.8.0_CACHE60_强化功能安全停用.sql`。该脚本只停用强化，不恢复已销毁装备。

## 公开部署安全

GitHub Pages公开包只包含游戏静态资源；不得放入GM单HTML、SQL或 `service_role`/Secret key。
GM入口：`ADMIN9 R9 · 九霄问道_ADMIN9_R9_手机直用版.html`，仅本地打开。
