## GitHub Pages

1. 解压本包并覆盖仓库根目录；
2. 提交全部文件，包括`.github/workflows/deploy-pages.yml`；
3. 推送`main`；
4. Settings → Pages → Source确认使用GitHub Actions；
5. 等待`build`和`deploy`均成功。

`B_HANDOFF/`用于继续发给B协作，构建白名单不会把它发布到正式网站。
