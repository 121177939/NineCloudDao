当前公开游戏基线：`v1-8-2-cache72-equipmentfx1`。

## CACHE72 装备强化双圈特效

- +1～+5：保留装备原始静态单圈。
- +6～+7：原内圈按照当前装备品级颜色旋转，不新增外圈。
- +8～+9：内圈停止，新增当前装备品级颜色的外圈旋转。
- +10：内圈停止，外圈改为黄、玄、地、天、仙五种品级色的连续渐变旋转。
- 适用于武器、衣服、裤子、鞋子和戒指。
- 不改变装备品级卡片边框，不增加文字光晕，不修改强化数值与战斗属性。
- 背包仍保持固定6×6布局与原格子大小。
