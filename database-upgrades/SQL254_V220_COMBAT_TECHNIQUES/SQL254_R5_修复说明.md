# SQL254 R5 · V2.2.0 CACHE122

本修订在 SQL254 尚未成功上线前继续沿用编号254。

- 不修改现有普通修炼功法生产掉率。
- 生产普通功法真实条件概率仍由 `main_rate + support_rate` 得到：玄4.1667%、地10%、天25%、仙50%；这些只是在“已经抽到对应品级且趋吉、进入普通功法判定”时使用，并非单次总机缘概率。
- 新攻防残卷：玄/地/天/仙继续严格取普通功法真实条件概率的20%。
- 黄品旧普通功法没有掉率行，因此新攻防黄品残卷改为独立条件概率5%，表示“黄品趋吉机缘内命中任意黄品攻防残卷池”的概率。
- 黄品5%进入GM独立配置 `opportunity_yellow_shard_rate`，默认0.05。
- API同时返回 `ordinary_drop_rates`（旧普通功法真实条件概率）与 `opportunity_shard_rates`（新攻防残卷池真实条件概率），避免再把仙品50%误读为单次机缘50%。

执行成功末尾必须出现 `SQL254_GATE_PASSED`。
