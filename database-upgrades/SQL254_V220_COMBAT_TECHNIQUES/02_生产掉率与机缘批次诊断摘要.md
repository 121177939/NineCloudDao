# SQL254 R5 · 生产普通功法掉率与机缘批次诊断摘要

生产只读诊断确认 `opportunity_v4_technique_drop_rates` 的字段为：`grade / main_rate / support_rate`。

旧普通修炼功法条件概率（已经抽到对应品级、且进入普通功法判定时）为：

- 玄品：2.7778% + 1.3889% = **4.1667%**
- 地品：6.6667% + 3.3333% = **10%**
- 天品：16.6667% + 8.3333% = **25%**
- 仙品：33.3333% + 16.6667% = **50%**

这些不是“所有机缘的总概率”。生产机缘会先抽品级，再抽趋吉/涉险；高品级机缘本身更稀有。SQL254 不修改上述旧普通功法配置。

## 新攻防残卷 R5 规则

- 黄品：旧普通功法表没有黄品行，因此不再使用玄品/最低值做假基准；**黄品趋吉机缘内，任意黄品攻防残卷池独立5%**，由 `opportunity_yellow_shard_rate` 配置，GM可调。
- 玄品：4.1667% × 20% = **0.8333%**。
- 地品：10% × 20% = **2%**。
- 天品：25% × 20% = **5%**。
- 仙品：50% × 20% = **10%**。

以上仍是“对应品级趋吉机缘内”的残卷池条件概率。命中池后再按攻伐/护体家族权重和同品单本权重决定具体残卷。

## 批量机缘

生产 `settle_opportunity_v4` 可一次离线补算多条机缘。SQL254 包装器按本次真实 `settlement_batch_id` 逐条读取 `opportunity_v3_results`，每一条符合条件的趋吉机缘独立判定新攻防残卷，避免只处理返回JSON中的少数摘要结果。
