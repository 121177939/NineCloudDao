# B-COMBAT01 基础数值与公式

## 公式

```text
常驻战力 = round(道攻×10 + 道御×8 + 生机×1.5 + 身法×5)

道御基础减伤 = min(道御 / (道御 + 防守方基础道攻×2), 70%)
总减伤 = min(1 - (1 - 道御减伤) × (1 - 护体功法减伤), 80%)
最终伤害 = floor(道攻 × 功法倍率 × 五行倍率 × 剑心倍率 × (1 - 总减伤))
```

境界系数仅用于装备要求与衰减，不再次乘入基础伤害。身法第一版只决定先手。

## 平衡验收结果

专项模拟共90项全部通过：

- 同一大境界低一小阶并拥有强克制：33组全部由低阶险胜。
- 同一大境界低两小阶并拥有弱克制：24组低阶全部失败。
- 跨一个大境界并拥有弱克制：9组低阶全部失败。
- 跨一个大境界且低阶同时拥有天生剑心8%：9组低阶仍全部失败。

关键锚点：

| 对战 | 结果 |
|---|---|
| 金丹初期克制金丹中期 | 金丹初期胜，剩80生机，8回合 |
| 金丹初期克制金丹后期 | 金丹后期胜，剩754生机，7回合 |

| 金丹圆满克制元婴初期 | 元婴初期胜，剩837生机，8回合 |
| 金丹圆满克制元婴初期且触发剑心8% | 元婴初期胜，剩662生机，8回合 |
