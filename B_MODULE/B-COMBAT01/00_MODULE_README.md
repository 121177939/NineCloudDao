# B-COMBAT01：五行战力榜与越阶挑战战报

## 身份与基线

- 身份：B线候选模块，不是正式发布。
- 唯一开发基线：`V0.15.5_FIX1_CACHE27`。
- B开发基线：`V0.15.5_AB14_CACHE27`。
- 原始部署包 SHA-256：`a7c09082e484add3e62de219361cfa5476f86c30e610547b8c122d239b002ffa`。

- 候选SQL没有在生产Supabase执行。

## 模块目标

1. 建立凡人至飞升的道攻、道御、生机、身法唯一基础表。
2. 为所有存量角色均衡随机补齐金木水火土，后续新角色自动从人数最少的五行中随机获得一种。
3. 开放市坊 → 天命榜 → 战力榜，并显示本尊战力、五行、境界与命格。
4. 只允许挑战战力高于自己的角色。
5. 点击挑战先显示双方快照确认弹窗，再播放逐回合战报。
6. 战报显示当前武器、当前功法、当前法衣、当前护体功法、五行关系、减伤、伤害与剩余生机。
7. 没有武器显示“赤手空拳”，没有衣服显示“赤裸”。
8. 败者损失战斗开始时当前修为的1%，胜者获得相同修为；不造成境界倒退。
9. 结算成功后同步九霄界闻，并按场景随机使用多组文案。

## 已锁定用户规则

- 战力：`道攻×10 + 道御×8 + 生机×1.5 + 身法×5`。
- 灵根类型只影响修炼速度；角色附属五行参与战斗克制。
- 身法第一版只决定先手。
- 每日主动挑战5次。
- 每名角色每日最多被有效挑战10次。
- 同一对手每日最多产生1次修为转移。
- 被挑战者战败后保护30分钟。
- 天生剑心只在“剑类武器 + 剑系功法”同时成立时，使剑系最终伤害提高8%；不提高四项属性，也不计入常驻战力。
- 五行可帮助低一小阶逆袭，但不能跨两小阶或跨大境界逆袭。

## 当前装备限制

V0.15.5 FIX1 CACHE27没有正式武器/衣服穿戴表。本模块因此新增**只允许服务端写入**的适配表 `character_combat_loadouts_bcombat01`：

- 未写入武器：战报显示“赤手空拳”，装备道攻为0。
- 未写入衣服：战报显示“赤裸”，装备道御、生机、身法为0。
- 将来正式装备模块接入后，由A线在装备穿戴事务中同步适配表；客户端不能直接写。

## 修为硬上限处理

胜者获得的修为先在当前境界硬上限内即时到账。若全额转入会突破既有硬上限，超出部分进入 `character_battle_cultivation_escrow_bcombat01`，不会凭空消失，也不会绕过正式突破规则。候选提供 `claim_battle_cultivation_escrow_bcombat01()`；A线应在突破成功后或登录结算链中调用。
