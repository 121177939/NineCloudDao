# A线验收场景

## 数据库

1. 前检全部为真。
2. 存量角色全部获得五行，五种人数最多相差1。
3. 并发创建新角色时均能获得五行，且分布持续接近均衡。
4. 天生剑心说明与效果改为剑类武器+剑系功法最终伤害8%。
5. 匿名用户不能读取新表或调用挑战结算。
6. 重复提交同一请求ID只结算一次。

## 战力榜

1. 本尊可看到自身战力、五行、境界与命格。
2. 只能点击挑战更高战力角色。
3. 同战力或低战力目标不可挑战。
4. 战力不包含五行与条件性剑心8%。

## 战斗表现

1. 当前武器、法衣、攻击功法、护体功法名称与快照一致。
2. 未配置武器显示“赤手空拳”。
3. 未配置法衣显示“赤裸”。
4. 每次攻击显示伤害、减伤和剩余生机。
5. 1倍、2倍与直接看结果仅影响播放，不改变结果。
6. 后续换装不能改写历史战报名称。

## 规则

1. 金丹初期克制金丹中期：低阶险胜。
2. 金丹初期克制金丹后期：低阶失败。
3. 金丹后期克制金丹圆满：低阶险胜。
4. 金丹圆满克制元婴初期：低阶失败。
5. 金丹圆满拥有剑心8%且克制元婴初期：仍失败。
6. 每日主动挑战第6次被拒绝。
7. 目标被有效挑战第11次被拒绝。
8. 同一对手第二次修为转移被拒绝。
9. 被挑战者失败后30分钟内不可再次被挑战。
10. 被挑战者获胜不进入保护。

## 修为与界闻

1. 败者扣除 `floor(战前修为×1%)`。
2. 胜者即时到账+暂存之和严格等于败者损失。
3. 败者修为不低于0，境界不倒退。
4. 结算与九霄界闻同时成功；任一步错误整场回滚。
5. 界闻包含胜负、回合和转移修为，并正确使用赤手/赤裸/越榜等场景文案。
