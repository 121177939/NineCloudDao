# B-PAIGOW01：九霄灵牌房间与牌九对局候选模块

## 身份与基线

- 身份：B线候选模块，不是正式发布。
- 唯一开发基线：`V1.2_AB22_CACHE37`（来源 `Jiuxiao_V1.2_CACHE37_Full.zip`）。
- 原始包 SHA-256：`ecbaf60a4a95b0a23fb07818bd9d1d0520892058ebcf3d42cc51f8dacc177e10`。
- 未修改正式版本号、CACHE37、Pages工作流或正式SQL迁移链。
- 候选SQL没有在生产Supabase执行。

## 模块目标

1. 从灵龟赌坊大堂移除可见的“气运龟卜”入口，替换为“九霄灵牌”。
2. 点击九霄灵牌进入独立全屏房间界面：创建房间、天地玄黄四房、选座、观战、进入对局。
3. 支持老何固定庄、玩家随机抢庄、玩家开船；支持牌九与大牌九；支持灵石或修为；底注自定义。
4. 房间最多4间，依次命名天字一号房、地字二号房、玄字三号房、黄字四号房；首局20分钟未开始自动关闭。
5. 老何庄100∶100等额输赢，资金只接入最新基线的 `casino_bankroll_v1`；不创建第二套赌场资金。
6. 玩家局按每笔确认赌注2.5%进入现有赌场资金。候选SQL用房间余数累计，保证整数资源长期精确等于2.5%。
7. 使用传统32张牌九骨牌、传统牌面与牌型名称；大牌九严格弱头先出、强尾后出。
