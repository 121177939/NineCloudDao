# 九霄灵牌设计规格

## 大堂与房间

- 原“气运龟卜”卡位改为“九霄灵牌”。
- 最多4间开放房，按空闲槽位命名天地玄黄。
- 创建项：老何VS玩家／玩家VS玩家；随机抢庄／开船；牌九／大牌九；灵石／修为；自定义底注。
- 房间创建20分钟仍未开始首局即关闭并释放槽位。
- 九席桌：牌九最多9名玩家；大牌九因32张牌每人4张，最多8名参战，第9席只作候补观战。

## 牌九

- 准备后每人两张，一张本人明牌、一张暗牌。
- 6秒选10／50／100倍，超时默认10倍并自动准备。
- 全员完成后统一开暗牌，显示传统牌型名称或点数。

## 大牌九

- 准备后先发两张本人明牌；选倍后补发两张本人私牌。
- 30秒自主组合或系统推荐；只允许头牌牌力≤尾牌牌力。
- 超时自动采用合法推荐。
- 全桌先亮弱头，展示10秒，再亮强尾；出牌不闪屏、不抖动。

## 玩家随机抢庄

- 发牌后、开牌前进入抢庄。
- 抢庄／不抢庄；多人抢庄在抢庄者中安全随机；无人抢庄在参战者中安全随机。
- 庄家确定后进入倍率阶段。

## 结算

- 老何庄：100∶100；玩家输款进入现有赌场资金，玩家盈利从现有赌场资金支付。
- 玩家局：每笔确认赌注2.5%进入现有赌场资金。
- 开船：赌注进入公共池，按牌力顺序赔付；并列组按组内赌注比例分配不足余额。
- 随机庄：闲家与庄家分别比较；庄家自赔，系统不兜底，手续费进入赌场资金。
