# 冲突说明

1. **赌场保护区**：本模块只调用现有资金与随机函数，不替换、不重建 `casino_bankroll_v1`、周期账本或安全随机。
2. **旧龟卜后端**：客户端移除可见入口，但候选不删除 `turtle_oracle` 数据库函数和历史记录，避免破坏回滚与旧账查询。A线确认无人调用后再另行清理。
3. **CACHE**：B候选不升CACHE37。正式并线必须由A线统一决定新缓存号并更新service worker清单。
4. **实时性**：当前试用HTML是前端状态演示；不得作为资金结算来源。生产必须使用RPC与数据库时间。
5. **大牌九人数**：32张牌只能支持8名四牌玩家；九席中的第9席为观战／候补，不能强行发36张。
6. **手续费整数**：候选用 `fee_carry_bps` 跨局累计小数余数；若A线改为40整数步进，必须同步客户端文案。
