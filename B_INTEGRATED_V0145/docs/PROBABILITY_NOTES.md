# 功法概率口径

以下概率均指“已经抽中对应品级并判定趋吉后”。

|品级|原主修概率|新增辅修概率|任意普通功法|
|---|---:|---:|---:|
|玄品|2/72=2.7778%|1/72=1.3889%|4.1667%|
|地品|3/45=6.6667%|1.5/45=3.3333%|10%|
|天品|4/24=16.6667%|2/24=8.3333%|25%|
|仙品|3/9=33.3333%|1.5/9=16.6667%|50%|

按基础品级概率和50%趋吉率估算，每次5分钟机缘的实际概率：

|品级|主修总概率|辅修总概率|
|---|---:|---:|
|天品|0.125%|0.0625%|
|仙品|0.08333%|0.04167%|

因此仙品的品级内比例虽高，实际总掉率仍低于天品。命格与气运会改变最终个人概率。
